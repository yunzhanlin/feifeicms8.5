# FeiFeiCMS 4.3 → ThinkPHP 8 完整迁移蓝图

> 本文档是开发和验收的唯一范围基线。项目目标是升级 FeiFeiCMS 本身，不是重新设计一个其他 CMS。

## 1. 迁移原则

- 以 `legacy/Lib/Lib/Action`、`legacy/Lib/Lib/Model`、`legacy/Public/system`、`legacy/Public/css`、`legacy/Tpl` 为功能和界面事实来源。
- 用 ThinkPHP 8.1、PHP 8.2–8.5、MySQL 8.4/InnoDB/utf8mb4 重写内核，不运行 TP2 兼容层。
- 保留 FeiFeiCMS 的后台导航、页面层级、字段含义、操作步骤、旧 URL 和模板标签语义；可以优化 CSS/JS 和数据存储，不得迫使旧用户重新学习。
- `vod_play` 与 `vod_url` 的 `$$$` 分组对齐、每集 `名称$URL`、`ff_url_*`、分类/人物/专题列表标签是兼容合同，不是可随意替换的实现细节。
- 新库可以规范化，但必须通过适配层完整提供旧字段、旧标签和旧路由所需的视图数据。

## 2. 技术基线

| 层 | 目标 | 兼容策略 |
|---|---|---|
| 框架 | ThinkPHP 8.1.x | 使用 TP8 路由、中间件、ORM、验证和视图，无 TP2 运行时 |
| PHP | 8.2–8.5 | 严格类型、无弃用语法，以宝塔 PHP-FPM 8.5 实际验收 |
| MySQL | 8.4 LTS | `ffx_*` 规范化表，InnoDB、utf8mb4、外键/唯一索引、严格模式 |
| 缓存 | Redis 8，文件降级 | 页面、查询、会话、限流、任务锁分区 |
| 搜索 | Meilisearch + MySQL 降级 | 保留可插拔搜索接口，可再接 Xunsearch；相关性 ID 顺序不被 SQL 二次打乱 |
| 前台 | MXOne 标签化模板 | 默认迁移 MXOne，模板可切换，业务查询不写死在页面中 |

## 4. 前台与 MXOne 功能矩阵

- 首页：幻灯、导航、推荐、分类板块、最新/热门、专题、资讯、友链。
- 分类：类型、地区、语言、年份、字母、状态、排序筛选与翻页。
- 搜索：关键词、联想、相关性、搜索记录、MySQL 降级。
- 详情：海报、简介、评分、人物、标签、多线路、分集、剧情/台词/观影/结局、相关推荐、评论。
- 播放：线路切换、分集切换、上/下集、历史、收藏、点赞/踩、试看/积分/VIP 权限、解析器选择。
- 资讯、专题、人物、角色、留言、站点地图、RSS、用户注册/登录/中心/收藏/记录/订单均进入同一模板合同。

MXOne 来源固定为旧项目中已保存的 `Tpl/mxone`、`Tpl/mxone-source` 和 `public/mxstatic`，不重新仿画。

## 5. 模板标签合同

- 模板可通过系统设置切换，模板不直接依赖 ORM。
- 兼容分配变量、`include`、`volist`、`foreach`、`if/elseif/else`、分页、URL 生成、字段格式化。
- 为常用 FeiFeiCMS 查询标签提供 `TemplateDataService`：影片、资讯、专题、人物、分类、标签、导航、幻灯、友链、评论。
- 视图适配层同时输出新字段和 `vod_id/vod_name/vod_pic/vod_play/vod_url/...` 等旧字段。
- 禁止模板执行任意 PHP、远程下载或直接写库；模板编辑需要权限、CSRF、路径白名单和审计。

## 6. 采集操作合同

1. “添加资源库”只要求名称、地址、AppKey（可选）、类型和启用状态。
2. 保存时自动检测 FeiFei/MacCMS JSON 协议，接口类型不由普通用户配置。
3. “进入资源库”读取上游名称、页数、数量、分类和影片列表，只读预览不写库。
4. 分类绑定使用“上游分类 → 本站分类”下拉框，内部再序列化为映射，界面不显示 JSON。
5. 支持采集当天、本周、全部、分类、关键词、指定 ID、勾选资源；任务可重试、防重、记录结果。
6. 内核保留 SSRF防护、超时、大小限制、不跟随重定向、密钥不明文展示等现代安全约束。

## 7. 数据库合同

- `ffx_media` 是影片主体；播放线路、分集、人物、多分类、标签、专题均使用关系表。
- 采集去重键为 `source_id + entity_type + external_id`，不以片名盲目覆盖。
- 旧库导入保存 ID 映射和原始 payload，逐表转换、数量对账、关联完整性检查，不长期双写。
- 时间库内按 UTC 存储，管理端和前台按站点时区展示。
- 数据库结构改动必须通过版本化 migration，不在控制器中临时 `ALTER TABLE`。

## 8. 验收门槛

- 静态：Composer 严格校验、依赖安全审计、PHP 8.2/8.3/8.4/8.5 语法矩阵、路由冲突检查。
- 数据：MySQL 8.4 空库安装、升级、外键、唯一索引、备份恢复；Redis/Meilisearch 正常与降级模式。
- 后台：对本表每个模块执行列表、新增、编辑、删除/禁用、筛选、分页、批量、权限、CSRF 和审计验收。
- 采集：使用已添加的资源库完成接口识别、分类读取、预览、绑定、小批量导入、更新去重与播放组对齐验证。
- 前台：MXOne 首页、分类、搜索、详情、播放、资讯、专题、人物、留言、用户和错误页做桌面/平板/手机同状态视觉与交互对照。
- 真实路径：在 `http://feifeicms-modern.localhost:19101/` 的宝塔 Nginx + PHP-FPM 中验收，不用只在 Docker/命令行通过代替。

## 9. 执行顺序

1. 以旧源码生成功能/字段/路由对照清单，固定兼容合同。
2. 恢复后台原版信息架构和采集操作链，补全业务功能。
3. 完成 FeiFeiCMS 模板数据适配层与标签合同。
4. 迁移 MXOne 页面与资源，接通全部前台功能。
5. 导入/升级工具、搜索、缓存、定时任务、备份恢复和安全收口。
6. 在本地宝塔逐页、逐操作、逐数据合同验收，保存截图和自动化记录。
