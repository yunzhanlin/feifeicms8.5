# 从 MXOne 制作自己的 FeiFeiCMS 模板

本指南适用于 FeiFeiCMS 8.5 的 ThinkPHP 8 模板。建议先在后台发布至少一条分类、一部带播放地址的视频，再访问 `/features` 看示例数据。下面的代码可放进 `.html` 模板；查询函数和字段以当前 8.5 程序为准，不能把旧版 4.3 的 PHP 模板文件原样覆盖到新站。

## 1. 十分钟做出第一套模板

1. 复制 `view/mxone/`，将副本命名为 `view/mytheme/`。目录名使用小写英文字母、数字和下划线。
2. 在副本里将 `{include file="mxone/..." /}` 改为 `{include file="mytheme/..." /}`，否则页面仍会引用 MXOne 的页头、页脚和卡片。可先保留 `/mxstatic/` 静态资源以验证页面；准备独立风格时，再把 `public/mxstatic/` 复制为 `public/mytheme/`，并替换模板中的资源路径。`view/mytheme/` 只放 `.html` 模板，不要放 CSS、JS、图片、下载文件或 PHP 脚本；资源路径用 `/mytheme/`，而不是 `/view/mytheme/`。模板源文件禁止直接访问和下载，预览请访问程序生成的前台页面。
3. 在 `view/mytheme/index/index.html` 修改首页布局，在 `view/mytheme/common/head.html` 引入自己的 CSS。下面的“最小首页”可以作为起点。
4. 后台“系统 → 全局配置 → 基本配置”选择“网站主模板”；如使用单独手机模板，也选择“移动端模板”，保存后清理模板缓存。刷新首页、分类页、详情页和播放页检查效果。

新模板至少要有下列文件才能出现在后台模板选项中；缺少其他页面时程序会尝试使用 MXOne 对应页面，不等于新模板已完整制作：

```text
view/mytheme/
├── common/head.html
├── common/header.html
├── common/footer.html
├── index/index.html
├── vod/type.html
├── vod/detail.html
├── vod/play.html
└── search/index.html
```

一个不依赖 MXOne 卡片组件的最小首页：

```html
{include file="mytheme/common/head" /}
{include file="mytheme/common/header" /}
<main class="my-container">
  <h1>{$siteName|htmlentities} · 最近更新</h1>
  <div class="my-grid">
    {volist name=":ff_mysql_vod('limit:12;order:vod_addtime;sort:desc')" id="item"}
    <a class="my-card" href="{:ff_url('vod',$item.vod_id)}">
      <img src="{$item.vod_pic|default='/static/images/no-poster.svg'|htmlentities}" alt="{$item.vod_name|htmlentities}">
      <strong>{$item.vod_name|htmlentities}</strong>
      <small>{$item.vod_year} · {$item.vod_type|htmlentities}</small>
    </a>
    {/volist}
  </div>
</main>
{include file="mytheme/common/footer" /}
```

例如在 `public/mytheme/site.css` 写自己的样式，并在 `common/head.html` 加 `<link rel="stylesheet" href="/mytheme/site.css">`。修改 CSS 不需要修改数据查询标签。

## 2. 先看懂模板语法

| 写法 | 作用 |
| --- | --- |
| `{$siteName}` | 输出当前页面变量；文本、属性建议加 `htmlentities`。 |
| `{$item.vod_pic\|default='/static/images/no-poster.svg'}` | 字段为空时显示默认值。 |
| `{volist name="vods" id="item"}...{/volist}` | 遍历控制器已传给页面的列表。 |
| `{volist name=":ff_mysql_vod('limit:8')" id="item"}...{/volist}` | 在模板中按条件查询并遍历。开头的 `:` 表示调用函数。 |
| `{notempty name="vods"}...{else /}暂无内容{/notempty}` | 列表有数据才展示。 |
| `{include file="mytheme/common/header" /}` | 引入本模板的公共文件，不写 `.html` 后缀。 |
| `{:ff_url('vod',$item.vod_id)}` | 按后台 URL 规则生成详情链接。 |

查询参数采用 `键:值;键:值`，例如 `cid:1;limit:12;order:vod_hits;sort:desc`。`cid`、`id` 等 ID 参数可写逗号分隔的多个正整数。`limit` 最多 200；这些函数返回有限数量的内容，不负责分页。需要完整分页时使用分类、搜索等页面控制器传入的 `vods` 和 `pager`。

## 3. 首页常用标签

### 分类导航

```html
<nav>
  {volist name=":ff_mysql_list('sid:1;limit:20')" id="type"}
  <a href="{:ff_url('type',$type.list_id)}">{$type.list_name|htmlentities}</a>
  {/volist}
</nav>
```

`sid:1` 取视频分类；`pid:1` 只取父分类为 1 的直接子类；`ids:1,2,3` 只取指定分类。也可直接用每页已提供的 `types`（视频顶级分类），减少重复查询。

### 最近更新、热播和某个分类

```html
<h2>最近更新</h2>
{volist name=":ff_mysql_vod('limit:8;order:vod_addtime;sort:desc')" id="item"}
  <a href="{:ff_url('vod',$item.vod_id)}">{$item.vod_name|htmlentities}</a>
{/volist}

<h2>热播</h2>
{volist name=":ff_mysql_vod('limit:8;order:vod_hits;sort:desc')" id="item"}
  <a href="{:ff_url('vod',$item.vod_id)}">{$item.vod_name|htmlentities}（{$item.vod_hits}）</a>
{/volist}

<h2>电影</h2>
{volist name=":ff_mysql_vod('cid:1;limit:8')" id="item"}
  <a href="{:ff_url('vod',$item.vod_id)}">{$item.vod_name|htmlentities}</a>
{/volist}
```

这里的 `cid:1` 是示例，请先在后台查看真实分类 ID。`ff_mysql_vod` 的 `cid` 只匹配列出的分类 ID，不会自动展开子分类；要同时显示子类，请列出所需 ID。首页控制器本身还提供 `latest`、`featured`、`channels`、`homeNews`、`homeSpecials` 和 `slides`，参考 `view/mxone/index/index.html` 可直接使用，避免相同区域再次查库。

支持的视频筛选：`cid`、`id`、`year`、`area`、`language`、`wd`/`name`、`actor`、`director`、`type`。`actor`、`director`、`type` 匹配影片扩展资料文本。可用排序键：`vod_id`、`vod_addtime`、`vod_hits`、`vod_hits_month`、`vod_gold`、`vod_stars`、`vod_up`、`vod_year`；`sort` 为 `asc` 或 `desc`。其中 `vod_hits_month` 当前与总播放量使用同一字段，不能当成独立月榜。

### 资讯、专题、人物与标签

```html
{volist name=":ff_mysql_news('limit:5;order:news_addtime')" id="news"}
  <a href="{:ff_url('news',$news.news_id)}">{$news.news_name|htmlentities}</a>
{/volist}
{volist name=":ff_mysql_special('limit:4')" id="special"}
  <a href="{:ff_url('special',$special.special_id)}">{$special.special_name|htmlentities}</a>
{/volist}
{volist name=":ff_mysql_star('limit:6')" id="person"}
  <a href="{:ff_url('person',$person.person_id)}">{$person.person_name|htmlentities}</a>
{/volist}
{volist name=":ff_mysql_tags('scope:media;limit:12')" id="tag"}
  <a href="/search?wd={$tag.tag_name|urlencode}">{$tag.tag_name|htmlentities}</a>
{/volist}
```

角色使用 `ff_mysql_role()`；资讯可按 `cid`/`id`/`wd`/`name` 查询，排序键为 `news_id`、`news_addtime`、`news_hits`、`news_stars`。专题可按 `cid`/`id` 查询；人物和角色可按 `id`/`wd`/`name` 查询；标签可用 `scope` 筛选。

### 轮播、导航、友链和广告

```html
{volist name=":ff_mysql_slide('limit:5')" id="slide"}
  <a href="{$slide.target_url|htmlentities}">
    <img src="{$slide.image_url|htmlentities}" alt="{$slide.name|htmlentities}">
  </a>
{/volist}
{volist name=":ff_mysql_nav('limit:20')" id="nav"}
  <a href="{$nav.url|htmlentities}">{$nav.title|htmlentities}</a>
{/volist}
{volist name=":ff_mysql_link('limit:20')" id="link"}
  <a href="{$link.link_url|htmlentities}" rel="noopener">{$link.link_name|htmlentities}</a>
{/volist}
{volist name=":ff_mysql_ads('slot:home_top;limit:1')" id="ad"}
  <div class="ad-slot">{$ad.ads_content|raw}</div>
{/volist}
```

广告内容允许 HTML，只应由可信任的后台管理员维护。常见广告位键有 `header`、`home_top`、`home_middle`、`vod_detail`、`vod_play`、`footer`。公共页面变量 `siteNavigation`、`siteSlides`、`friendLinks`、`siteAds` 也可直接使用；例如 `{notempty name="siteAds.home_top"}{$siteAds.home_top|raw}{/notempty}`。

## 4. 详情、播放与分集剧情

视频详情页 `vod/detail.html` 已有 `vod`、`sources`、`scenarios`、`related`、`tags`、`credits`、`rating`、`access` 等变量。常用字段可直接输出：

```html
<h1>{$vod.vod_name|htmlentities}</h1>
<p>{$vod.vod_year} · {$vod.vod_area|htmlentities} · {$vod.vod_language|htmlentities}</p>
<p>主演：{$vod.vod_actor|default='暂无'|htmlentities}</p>
<p>导演：{$vod.vod_director|default='暂无'|htmlentities}</p>
<p>{$vod.vod_content|strip_tags|htmlentities}</p>
{notempty name="vod.vod_douban_id"}<p>豆瓣 ID：{$vod.vod_douban_id|htmlentities}</p>{/notempty}
{notempty name="vod.vod_imdb_id"}<p>IMDb ID：{$vod.vod_imdb_id|htmlentities}</p>{/notempty}

{if !empty($access.allowed)}
  {volist name="sources" id="source" key="sourceIndex"}
    <h2>{$source.name|htmlentities}</h2>
    {volist name="source.episodes" id="episode" key="episodeIndex"}
      <a href="{:ff_play_url($vod.vod_id,$sourceIndex-1,$episodeIndex-1)}">{$episode.title|htmlentities}</a>
    {/volist}
  {/volist}
{else /}
  <p>此视频需满足观看权限后才能播放。</p>
{/if}
```

`ff_play_url(影片ID, 线路下标, 分集下标)` 的**函数参数从 0 开始**；生成的公开 URL 中线路和分集**从 1 开始**。例如 `ff_play_url(16,0,0)` 对应第一条线路的第一集。模板里的 `{volist ... key="sourceIndex"}` 从 1 开始，所以调用时要减 1。不要自己拼接 `/play/...`，后台修改 URL 规则后函数仍能生成正确链接。权限判断不能只靠模板隐藏按钮，服务端播放页仍会校验权限。

播放页 `vod/play.html` 已提供 `currentSource`、`current`、`sources`、`sid`、`pid`、`prevUrl`、`nextUrl`、`access` 和播放器所需参数。直接参考 MXOne 播放页的 `data-ff-player` 容器及 `/static/js/player.js` 引用；仅输出远程地址不等同于支持 HLS、解析和弹幕。

分集剧情存放于独立表，详情页可用 `scenarios` 和 `scenarioCount`；完整剧情页为 `/vod/{影片ID}/scenarios`，单集链接请用 `ff_url('scenario',剧情ID)`：

```html
{notempty name="scenarios"}
  {volist name="scenarios" id="scenario"}
    <a href="{:ff_url('scenario',$scenario.id)}">第 {$scenario.episode_no} 集 · {$scenario.title|htmlentities}</a>
  {/volist}
{/notempty}
```

需要从其他页面查询某部影片的剧情时，可以使用 `ff_mysql_scenario('vodid:16;limit:30')`；`vodid` 是本地影片 ID，不是来源站的远程 ID。

评论示例：`ff_mysql_forum('cid:16;limit:10')` 取影片 16 的已审核评论；`ff_mysql_forum('target:site;limit:10')` 取站点留言。输出评论内容时使用 `htmlentities`，不要对用户内容使用 `raw`。

## 5. 页面数据和常用字段速查

| 页面文件 | 已提供的主要变量 |
| --- | --- |
| `index/index.html` | `latest`、`featured`、`channels`、`homeNews`、`homeSpecials`、`slides` |
| `vod/type.html` | `type`、`vods`、`vodTotal`、`filters`、`filterOptions`、`pager` |
| `search/index.html` | `keyword`、`vods`、`total`、`page`、`pages`、`message` |
| `vod/detail.html` | `vod`、`sources`、`scenarios`、`scenarioCount`、`tags`、`credits`、`rating`、`related`、`access` |
| `vod/play.html` | `vod`、`sources`、`currentSource`、`current`、`sid`、`pid`、`prevUrl`、`nextUrl` |
| `news/index.html` / `news/detail.html` | `news`、`pager` / `item` |
| `special/index.html` / `special/detail.html` | `specials`、`pager` / `item`、`vods` |
| `person/index.html` / `person/detail.html` | `people`、`pager` / `item`、`vod` |

每个前台页面还共享 `siteName`、`seo`、`types`、`siteNavigation`、`siteSlides`、`friendLinks`、`siteAds`、`hotSearches` 等变量。电影卡片常用 `vod_id`、`vod_name`、`vod_pic`、`vod_type`、`vod_year`、`vod_area`、`vod_language`、`vod_hits`、`vod_gold`、`vod_actor`、`vod_director`、`remark_text`。资讯用 `news_id`、`news_name`、`news_pic`，专题用 `special_id`、`special_name`，人物用 `person_id`、`person_name`、`person_pic`。

视频关键词使用 `{$vod.vod_keywords|default='暂无'}`（`vod_tag` 为兼容别名），优先读取标签/关键词，缺少时使用来源的扩展类型。上映/播出使用 `{$vod.vod_pubdate|default='暂无'}`：完整日期为 `YYYY-MM-DD`，来源只提供年份或月份时保留原文，不会编造月日。旧标签 `vod_filmtime` 仍为 Unix 时间戳，没有完整日期时为 `0`，不能把它当字符串日期直接输出。

## 6. 链接、分页与排错

- 详情/分类/资讯/专题/人物：分别用 `ff_url('vod',ID)`、`ff_url('type',ID)`、`ff_url('news',ID)`、`ff_url('special',ID)`、`ff_url('person',ID)`。
- 搜索表单：`<form action="/search" method="get"><input name="wd"><button>搜索</button></form>`。不要把关键词未经编码直接拼进 URL。
- 分类、资讯等分页：控制器已传 `pager`，可用 `<div class="pager">{$pager|raw}</div>`。只有这个由分页器生成的 HTML 才直接输出 `raw`。
- 模板不出现在后台：检查第 1 节的八个必需文件、目录名和文件权限。
- 页面仍像 MXOne：检查副本中的 `mxone/` include、`/mxstatic/` 资源引用以及后台选中的主/移动模板；清理模板缓存。
- 查询为空：确认内容已发布、分类 ID 正确、图片/线路有数据；`ff_mysql_*` 默认只取已发布或已启用内容，不要为了展示草稿在公开页面使用 `status:all`。
- 详情能打开而播放 404：确认该影片有播放线路与分集，并用 `ff_play_url()` 生成链接。
- CSS 改了不生效：清理浏览器缓存或给自己的 CSS URL 添加版本参数；不要为了改颜色去修改数据标签。

完整页面与样式可对照 `view/mxone/`；`/features` 展示当前站点真实数据和调用示例。建议先做出一个可用的首页和影片卡片，再依次替换分类、详情、播放和其他页面。
