# FeiFeiCMS 8.5 模板制作与标签调用教程

本指南适用于 FeiFeiCMS 8.5 的 ThinkPHP 8 模板。建议先在后台发布至少一条分类、一部带播放地址的视频，再访问 `/features` 看示例数据。下面的代码可放进 `.tpl` 模板；查询函数和字段以当前 8.5 程序为准。

本文针对 **8.5.261023.2**，仅参考 [标签说明文档](https://github.com/MyPHPTools/feifeicms/blob/master/%E6%96%B0%E5%A2%9E%E6%A8%A1%E7%89%88%E6%A0%87%E7%AD%BE%E8%AF%B4%E6%98%8E.txt) 的组织格式：**标签说明 → 参数 → 调用示例 → 返回字段**。所有函数、语法和字段均来自 FeiFeiCMS 8.5，不使用参考项目的模板标签，也不把本文当成旧模板迁移手册。

## 1. 十分钟做出第一套模板

1. 复制 `view/mxone/`，将副本命名为 `view/mytheme/`。目录名建议使用小写英文字母、数字、下划线或短横线。
2. 再复制 `public/theme-assets/mxone/` 为 `public/theme-assets/mytheme/`，两个目录的主题名必须一致。`view/mytheme/` 只放 `.tpl` 和私有 `extensions/` PHP 扩展；CSS、JS、图片和字体放公开资源目录。`{include file="common/head" /}` 相对于当前模板，`ff_theme_asset()` 自动使用当前主题名，不必逐个修改 `mxone`。模板和 PHP 源码不能直接访问或下载。
3. 在 `view/mytheme/index/index.tpl` 修改首页布局，在 `view/mytheme/common/head.tpl` 引入自己的 CSS。下面的“最小首页”可以作为起点。
4. 后台“系统 → 全局配置 → 基本配置”选择“网站主模板”。同一套自适应模板用于所有设备时，“移动端模板”也选 `mytheme`；程序按浏览器 User-Agent 选择主模板或移动模板。保存后在“工具 → 缓存管理”清理编译与模板缓存，刷新首页、分类页、详情页和播放页检查效果。

新模板至少要有下列文件才能出现在后台模板选项中；缺少其他页面时程序会尝试使用 MXOne 对应页面，不等于新模板已完整制作：

```text
view/mytheme/
├── common/head.tpl
├── common/header.tpl
├── common/footer.tpl
├── index/index.tpl
├── vod/type.tpl
├── vod/detail.tpl
├── vod/play.tpl
├── search/index.tpl
└── extensions/functions.php

public/theme-assets/mytheme/
├── css/site.css
├── js/app.js
└── images/logo.png
```

这 8 个文件及其路径组件不能是软链接。它们只是后台可选模板的最低要求，完整制作应复制整套 MXOne；其他页面目录包括 `news/`、`special/`、`person/`、`user/`、`guestbook/`、`forum/`、`page/`，剧情和完整评论页在 `vod/` 下。后台 `view/admin/` 和安装 `view/install/` 不属于前台模板。

网站运行目录必须指向项目 `public/`，不能指向项目根目录。`view/` 始终是私有模板目录，禁止设置公开映射或软链接。`public/theme-assets/` 中的真实文件通过 `/theme-assets/{主题名}/{资源路径}` 直接访问，不需要额外资源伪静态，不经过 PHP。该目录完全公开，只能放 CSS、JS、图片和字体，不能放 `.tpl`、PHP、配置、密钥或软链接。安全配置见 [安装说明](../README.md#安装说明)。

一个不依赖 MXOne 卡片组件的最小首页：

```html
{include file="common/head" /}
{include file="common/header" /}
<main class="my-container">
  <h1>{$siteName} · 最近更新</h1>
  <div class="my-grid">
    {volist name=":ff_mysql_vod('limit:12;order:vod_addtime;sort:desc')" id="item"}
    <a class="my-card" href="{:htmlentities(ff_url('vod',$item.vod_id))}">
      <img src="{$item.vod_pic|default='/theme-assets/shared/images/no-poster.svg'}" alt="{$item.vod_name}">
      <strong>{$item.vod_name}</strong>
      <small>{$item.vod_year} · {$item.vod_type}</small>
    </a>
    {/volist}
  </div>
</main>
{include file="common/footer" /}
```

例如在 `public/theme-assets/mytheme/css/site.css` 写自己的样式，并在 `view/mytheme/common/head.tpl` 加 `<link rel="stylesheet" href="{:ff_theme_asset('css/site.css')}">`。先创建文件再引用。返回地址自动带内容指纹，修改 CSS 或 JS 后会更新缓存地址，不需要手工改版本号，也不需要修改数据查询标签。CSS 内可用 `url('../images/logo.png')` 引用同主题图片。

如果要从头设计页头，`common/head.tpl` 最少应保留视口、SEO 和可用页面的 CSRF 信息：

```html
<!doctype html>
<html lang="zh-CN">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>{$seo.title}</title>
  <meta name="keywords" content="{$seo.keywords}">
  <meta name="description" content="{$seo.description}">
  {notempty name="csrf"}<meta name="csrf-token" content="{$csrf}">{/notempty}
```

这是首页用的最小页头，`common/footer.tpl` 要关闭 `</body></html>`。制作播放和互动页面时，须补回第 4、8 节的 JS 依赖，不能用最小页头替换后就认为整套功能已完成。

### 主题资产与 PHP 展示扩展

| 方法 | 用法 |
| --- | --- |
| `ff_theme_asset('css/site.css')` | 当前实际渲染主题的静态资源；复制整套主题后自动随主题切换。 |
| `ff_asset_url('shared','player/player.js')` | 共享播放器等明确归属其他内置包的资源。 |
| `ff_theme_call('duration',90)` | 调用当前主题 `extensions/functions.php` 返回数组中的命名方法。 |

在自己的 `extensions/functions.php` 写：

```php
<?php
declare(strict_types=1);
return [
    'duration' => static fn (mixed $minutes): string => (int) $minutes > 0 ? (int) $minutes . '分钟' : '暂无',
];
```

然后在 `.tpl` 中使用 `{:ff_theme_call('duration',90)}`，输出 `90分钟`。不同主题的扩展互相隔离，不要在扩展文件定义可能重名的全局函数；返回命名函数数组即可。系统的 `ff_mysql_*`、`ff_url()` 等公共标签位于 `view/shared/extensions/tags.php`，制作新主题不需要复制或修改它。

PHP 扩展是可信开发者部署的服务端代码，不是供访客上传的插件，不开放后台在线编辑、下载或任意路径调用。只用于格式化、显示等主题逻辑；认证、付费、权限和写数据库仍由 `app/` 负责。4.3 数据迁移插件仍独立位于 `plugins/legacy43/`，它不是模板插件，不随模板复制。

后台“工具 → 模板管理”可编辑前台主题的 `.tpl`，主题下的“assets”入口对应 `public/theme-assets/<主题名>/`，可编辑其中的 CSS、JS；PHP、图片和字体只显示文件信息。编辑器会显示实际存储路径。页面 URL 仍可使用 `.html` 伪静态后缀，与磁盘上的 `.tpl` 后缀无关。

从旧布局升级时先备份程序并更新 Nginx／宝塔规则，再重载 PHP-FPM。旧版内置 `/mxstatic/`、`/static/` 和 `/player/vendor/` 链接有兼容读取入口，但新模板不要再写这些旧地址。自制旧 `.html` 主题须将模板转换成 `.tpl`、把 include 改为主题内相对引用，并将资源与 PHP 扩展归入上述结构；保留原文件和备份，验收后再清理。

## 2. 先看懂模板语法

| 写法 | 作用 |
| --- | --- |
| `{$siteName}` | 输出页面变量，8.5 模板默认自动执行 HTML 转义，文本和属性均可使用。 |
| `{$item.vod_pic\|default='/theme-assets/shared/images/no-poster.svg'}` | 字段为空时显示默认值。 |
| `{volist name="vods" id="item"}...{/volist}` | 遍历控制器已传给页面的列表。 |
| `{volist name=":ff_mysql_vod('limit:8')" id="item"}...{/volist}` | 在模板中按条件查询并遍历。开头的 `:` 表示调用函数。 |
| `{notempty name="vods"}...{else /}暂无内容{/notempty}` | 列表有数据才展示。 |
| `{include file="common/header" /}` | 引入本模板的公共文件，不写 `.tpl` 后缀。 |
| `{:htmlentities(ff_url('vod',$item.vod_id))}` | 按后台规则生成详情 URL，函数结果单独转义后用于 HTML 属性。 |

查询参数采用 `键:值;键:值`，例如 `cid:1;limit:12;order:vod_hits;sort:desc`。`cid`、`id` 等 ID 参数可写逗号分隔的多个正整数。`limit` 最多 200；这些函数返回有限数量的内容，不负责分页。需要完整分页时使用分类、搜索等页面控制器传入的 `vods` 和 `pager`。

分类等列表有 `pager`，但**搜索没有 `pager`**，需用 `page`、`pages`，详见第 7 节。循环记录变量 `id="item"` 可以自定义，嵌套时避免重名；`key="rank"` 从 1 开始，展示已有数组的一部分可用 `offset`、`length`：

```html
{volist name="latest" id="item" key="rank" offset="4" length="8"}
  <a href="{:htmlentities(ff_url('vod',$item.vod_id))}">{$rank}. {$item.vod_name}</a>
{/volist}
{empty name="latest"}<p>还没有发布视频。</p>{/empty}
```

`offset="4"` 跳过前 4 条，从第 5 条开始最多展示 8 条；它只裁切已有数组，不改变 SQL，不会从数据库补齐条数。循环的 `key` 是循环计数，不是数据库 ID。

### 中文截取、日期和安全输出

```html
<p>{$vod.vod_name|mb_substr=0,20}</p>
<p>{$vod.vod_content|strip_tags}</p>
{if $vod.vod_addtime > 0}<time>{$vod.vod_addtime|date='Y-m-d H:i'}</time>{/if}
```

使用 `mb_substr` 截取中文，`date` 只用于时间戳。`vod_pubdate` 是日期原文，直接输出即可。正文含 HTML 实体时可先 `html_entity_decode`，再 `strip_tags`；不能解码后直接输出用户内容。

`raw` 表示不转义，仅用于可信管理员维护的广告／允许 HTML 的正文，以及程序生成的分页或已转义评论 HTML。片名、昵称、留言和用户地址应保持默认转义，属性值也一样；JS 优先通过 `data-*` 属性取值，不直接拼进脚本。

### 13 类查询函数一览

**变量与函数输出的转义规则不同。**`{$变量}` 及其过滤链默认自动执行 `htmlentities`，无需再追加 `|htmlentities` 或 `|htmlspecialchars`，否则会重复转义。`{:函数(...)}` 直接输出函数结果，不自动转义；本文在链接属性中使用 `{:htmlentities(ff_url(...))}`，只转义一次。不要用 `raw` 绕过变量的安全转义，也不要关闭模板引擎的默认过滤。

| 函数 | 数据 | 默认条数 | 专用筛选 |
| --- | --- | ---: | --- |
| `ff_mysql_list()` | 分类 | 50 | `sid`、`pid`、`ids` |
| `ff_mysql_vod()` | 视频 | 20 | `cid`、`id`、`year`、`area`、`language`、`wd`／`name`、`actor`、`director`、`type` |
| `ff_mysql_news()` | 资讯 | 20 | `cid`、`id`、`wd`／`name` |
| `ff_mysql_special()` | 专题 | 20 | `cid`、`id` |
| `ff_mysql_star()` | 明星 | 20 | `id`、`wd`／`name` |
| `ff_mysql_role()` | 角色 | 20 | `id`、`wd`／`name` |
| `ff_mysql_tags()` | 标签 | 50 | `scope` |
| `ff_mysql_slide()` | 轮播 | 10 | 无专用筛选 |
| `ff_mysql_nav()` | 导航 | 50 | 无专用筛选 |
| `ff_mysql_link()` | 友链 | 50 | 无专用筛选 |
| `ff_mysql_ads()` | 广告 | 20 | `slot` |
| `ff_mysql_scenario()` | 剧情 | 100 | `vodid`／`cid`、`id` |
| `ff_mysql_forum()` | 评论、留言 | 30 | `target`、`cid` |

全部支持 `limit`，限于 1～200；不支持自动分页、查询偏移或返回总数。当前 `limit:4,8` 只取最后的 `8` 作为条数，不会跳过前 4 条；改用明确的条数和 `volist offset/length`，或页面分页。

只有视频、资讯标签处理 `order`、`sort`。其他函数固定按程序规定排序。未知参数一般被忽略，因此“没报错”不等于条件生效。不要传任意 `where` SQL，也不要把未经校验的请求参数拼入整个标签字符串；普通用户搜索请使用搜索页面。

内容标签默认取已发布未归档记录，评论取已审核记录，运营组件取已启用记录；标签本身没有发布状态筛选。视频、分类适配器保留 `status:all`，公开模板禁止使用，以免展示隐藏内容。模板是可信代码，不应允许访客上传或编辑模板。

## 3. 首页常用标签

### 分类导航

```html
<nav>
  {volist name=":ff_mysql_list('sid:1;limit:20')" id="type"}
  <a href="{:htmlentities(ff_url('type',$type.list_id))}">{$type.list_name}</a>
  {/volist}
</nav>
```

`sid:1` 取视频分类；`pid:1` 只取父分类为 1 的直接子类；`ids:1,2,3` 只取指定分类。也可直接用每页已提供的 `types`（视频顶级分类），减少重复查询。`ff_mysql_list('pid:0')` 不起父分类过滤作用，不能代替 `types` 取顶级分类。

| 参数 | 含义 |
| --- | --- |
| `sid` | `1` 视频、`2` 资讯、`3` 专题、`8`／`9` 人物分类；不用于区分具体人物的明星／角色身份 |
| `pid` | 父分类 ID，非零时取直接子类 |
| `ids` | 分类 ID，多个用逗号分隔 |
| `limit` | 默认 50，上限 200 |

返回按父 ID、后台排序、ID 升序排列的分类。字段有 `list_id`、`list_name`、`list_pid`、`list_oid`（排序）、`list_dir`（目录别名）、`list_link`（分类 URL）、`list_extend`（筛选配置数组），以及 `type_id`、`type_name`、`type_pid`。例：

```html
{volist name=":ff_mysql_list('sid:1;pid:1;limit:20')" id="child"}
  <a href="{$child.list_link}">{$child.list_name}</a>
{/volist}
```

### 最近更新、热播和某个分类

```html
<h2>最近更新</h2>
{volist name=":ff_mysql_vod('limit:8;order:vod_addtime;sort:desc')" id="item"}
  <a href="{:htmlentities(ff_url('vod',$item.vod_id))}">{$item.vod_name}</a>
{/volist}

<h2>热播</h2>
{volist name=":ff_mysql_vod('limit:8;order:vod_hits;sort:desc')" id="item"}
  <a href="{:htmlentities(ff_url('vod',$item.vod_id))}">{$item.vod_name}（{$item.vod_hits}）</a>
{/volist}

<h2>电影</h2>
{volist name=":ff_mysql_vod('cid:1;limit:8')" id="item"}
  <a href="{:htmlentities(ff_url('vod',$item.vod_id))}">{$item.vod_name}</a>
{/volist}
```

这里的 `cid:1` 是示例，请先在后台查看真实分类 ID。`ff_mysql_vod` 的 `cid` 只匹配列出的分类 ID，不会自动展开子分类；要同时显示子类，请列出所需 ID。首页控制器本身还提供 `latest`、`featured`、`channels`、`homeNews`、`homeSpecials` 和 `slides`，参考 `view/mxone/index/index.tpl` 可直接使用，避免相同区域再次查库。

支持的视频筛选：`cid`、`id`、`year`、`area`、`language`、`wd`/`name`、`actor`、`director`、`type`。`actor`、`director`、`type` 匹配影片扩展资料文本。可用排序键：`vod_id`、`vod_addtime`、`vod_hits`、`vod_hits_month`、`vod_gold`、`vod_stars`、`vod_up`、`vod_year`；`sort` 为 `asc` 或 `desc`。其中 `vod_hits_month` 当前与总播放量使用同一字段，不能当成独立月榜。

| 参数 | 准确含义与示例 |
| --- | --- |
| `cid` | 本地分类 ID，可多个；精确匹配，不自动展开子类 |
| `id` | 本地视频 ID，可多个，如 `id:16,20`；结果按排序规则，不按输入 ID 顺序 |
| `year` | 年份精确匹配，如 `year:2026` |
| `area`、`language` | 包含匹配，如 `area:中国大陆;language:国语` |
| `wd`／`name` | **只在片名中**包含匹配，不等于前台搜索的查询范围 |
| `actor`、`director`、`type` | 在 metadata 文本中包含匹配，当前不是对应独立字段的精确筛选 |
| `order` | 一个排序键，例如 `order:vod_hits`；不写空格与 `desc`，不支持 `rand()` |
| `sort` | `asc`／`desc`，默认降序 |
| `limit` | 默认 20，上限 200 |

**特别注意：视频标签的 `ids` 当前是分类 ID 的兼容入口，不是指定影片 ID；同时传 `cid` 与 `ids` 时用 `cid`。**要指定影片只能写 `id:16,20`。

`vod_addtime` 排序对应更新时间，`vod_stars` 排序对应 `weight` 权重，不是首次入库时间或星级筛选。默认按更新时间降序、同值再按 ID 降序，无效排序键回退默认。首页、最近更新页、分类页主要按发布时间组织，不能与标签更新时间排序混用。

```html
<!-- 指定影片：id，不是 ids -->
{volist name=":ff_mysql_vod('id:16,20;limit:2')" id="item"}
  <a href="{:htmlentities(ff_url('vod',$item.vod_id))}">{$item.vod_name}</a>
{/volist}
<!-- 某年、地区和语言的影片 -->
{volist name=":ff_mysql_vod('year:2026;area:中国大陆;language:国语;limit:6')" id="item"}
  <a href="{:htmlentities(ff_url('vod',$item.vod_id))}">{$item.vod_name}</a>
{/volist}
<!-- 分类及后代：ff_list_ids 返回逗号分隔的本地分类 ID -->
{volist name=":ff_mysql_vod('cid:'.ff_list_ids(1).';limit:12')" id="item"}
  <a href="{:htmlentities(ff_url('vod',$item.vod_id))}">{$item.vod_name}</a>
{/volist}
```

优先用首页已有 `latest`、`featured`、`channels`，它们有数据缓存。标签查询不保证每种组合都走相同缓存；不要在几十张卡片里再次查询分类、人物或剧情，也不要增大 `limit` 来代替分页。

### 资讯、专题、人物与标签

```html
{volist name=":ff_mysql_news('limit:5;order:news_addtime')" id="news"}
  <a href="{:htmlentities(ff_url('news',$news.news_id))}">{$news.news_name}</a>
{/volist}
{volist name=":ff_mysql_special('limit:4')" id="special"}
  <a href="{:htmlentities(ff_url('special',$special.special_id))}">{$special.special_name}</a>
{/volist}
{volist name=":ff_mysql_star('limit:6')" id="person"}
  <a href="{:htmlentities(ff_url('person',$person.person_id))}">{$person.person_name}</a>
{/volist}
{volist name=":ff_mysql_tags('scope:media;limit:12')" id="tag"}
  <a href="{:htmlentities(ff_url('search',['wd'=>$tag.tag_name]))}">{$tag.tag_name}</a>
{/volist}
```

角色使用 `ff_mysql_role()`；资讯可按 `cid`/`id`/`wd`/`name` 查询，排序键为 `news_id`、`news_addtime`、`news_hits`、`news_stars`。专题可按 `cid`/`id` 查询；人物和角色可按 `id`/`wd`/`name` 查询；标签可用 `scope` 筛选。

| 查询 | 参数与固定行为 | 返回常用字段 |
| --- | --- | --- |
| `ff_mysql_news` | `cid` 资讯分类、`id` 资讯 ID、`wd`／`name` 搜标题；支持白名单排序和 `sort`，默认发布时间降序、ID 降序 | `news_id`、`news_name`、`news_pic`、`news_hits`、`news_addtime`、`news_link`、`summary_text`、`safe_content` |
| `ff_mysql_special` | `cid` 专题分类、`id` 专题 ID；固定按发布时间、ID 降序 | `special_id`、`special_name`、`special_description`、`special_hits`、`special_link`、`cover`、`summary_text`、`safe_content` |
| `ff_mysql_star`／`ff_mysql_role` | `id` 人物 ID、`wd`／`name` 搜姓名；固定筛选明星／角色，按更新时间、ID 降序 | `person_id`、`person_name`、`person_pic`、`person_sid`（明星 8、角色 9）、`person_alias`、`person_profession`、`person_gender`、`person_birthday`、`person_nationality`、`person_astrology`、`person_school`、`person_hits`、`person_link`、`safe_content` |
| `ff_mysql_tags` | `scope` 精确筛选范围，例如 `media`；按 ID 降序 | `tag_id`、`tag_name`、`tag_list`（scope）、`tag_count` |

`news_link`、`special_link`、`person_link` 是查询附加字段，页面控制器转换的数据不保证带这些字段，所以跨页面优先用 `ff_url()`。资讯／专题／人物详情分别使用 `item.news_name`、`item.special_name`、`item.person_name`，不是 `item.vod_name`。

正文的 `safe_content` 按后台 HTML 开关生成，仅适合可信后台正文；使用 `{$item.safe_content|raw}` 可保留排版，纯文本可用 `{$item.content|strip_tags}`。人物正文原始字段是 `biography`。

专题详情 `vods` 是关联影片，人物详情 `vod` 是关联作品**列表**；不要拿专题／人物 ID 当视频分类 ID。影片 `credits` 是演职关系，字段为 `id`、`name`、`avatar_url`、`credit_type`、`character_name`，不是 `person_*`。主演文本有值不代表已建立人物记录与演职关联。

标签 `tag_count` 当前是兼容占位值 `0`，不能显示成真实关联数量。示例链接是关键词搜索，不是按标签 ID 的精确关联查询；视频详情页的 `tags` 使用原始 `id`、`name`、`scope`，显示时写 `{$tag.name}`。

角色标签的独立示例，使用后台人物模块建立的角色记录：

```html
{volist name=":ff_mysql_role('limit:6')" id="character"}
  <a href="{:htmlentities(ff_url('role',$character.person_id))}">{$character.person_name}</a>
{/volist}
```

### 轮播、导航、友链和广告

```html
{volist name=":ff_mysql_slide('limit:5')" id="slide"}
  <a href="{$slide.target_url}">
    <img src="{$slide.image_url}" alt="{$slide.name}">
  </a>
{/volist}
{volist name=":ff_mysql_nav('limit:20')" id="nav"}
  <a href="{$nav.url}">{$nav.title}</a>
{/volist}
{volist name=":ff_mysql_link('limit:20')" id="link"}
  <a href="{$link.link_url}" rel="noopener">{$link.link_name}</a>
{/volist}
{volist name=":ff_mysql_ads('slot:home_top;limit:1')" id="ad"}
  <div class="ad-slot">{$ad.ads_content|raw}</div>
{/volist}
```

广告内容允许 HTML，只应由可信任的后台管理员维护。常见广告位键有 `header`、`home_top`、`home_middle`、`vod_detail`、`vod_play`、`footer`。公共页面变量 `siteNavigation`、`siteSlides`、`friendLinks`、`siteAds` 也可直接使用；例如 `{notempty name="siteAds.home_top"}{$siteAds.home_top|raw}{/notempty}`。

| 查询 | 可用参数与排序 | 字段与边界 |
| --- | --- | --- |
| `ff_mysql_slide` | 仅 `limit`，默认 10；后台排序、ID 升序 | `name`、`image_url`、`mobile_image_url`、`target_url` 等原始字段；只过滤启用状态，不过滤有效期 |
| `ff_mysql_nav` | 仅 `limit`，默认 50；后台排序、ID 升序 | `id`、`parent_id`、`title`、`url`、`target`；扁平列表，不支持 `pid` 参数 |
| `ff_mysql_link` | 仅 `limit`，默认 50；后台排序、ID 升序 | `link_id`、`link_name`、`link_url`、`link_logo`、`link_type` |
| `ff_mysql_ads` | `slot` 广告位键、`limit`（默认 20）；ID 升序 | `ads_id`、`ads_name`、`ads_key`、`ads_content`；过滤启用状态和开始／结束时间 |

轮播有有效期时使用 `siteSlides`，它会过滤时间；首页的 `slides` 来自同一份公共数据。单独 `ff_mysql_slide()` 不保证这一点。列表标签只取图片，不会自动产生动画；保留 MXOne 的 `data-hero-slider`、`data-hero-dot` 结构及 JS，或自行编写轮播交互。

`siteNavigation` 是顶级导航，其子导航在 `siteNavigationChildren`，不是另传 `pid` 给查询函数。公共 `friendLinks` 是 `name/url/logo_url/link_type` 原始字段，查询返回的兼容字段则是 `link_name/link_url/link_logo/link_type`，二者不要混用。

`siteAds` 每个位置映射为一段内容，不是该位置所有广告组成的数组；需要多条时使用 `ff_mysql_ads('slot:home_top;limit:3')` 遍历。普通页面优先用缓存好的公共组件，未配置内容时不保留大块空白占位。

## 4. 详情、播放与分集剧情

视频详情页 `vod/detail.tpl` 已有 `vod`、`sources`、`scenarios`、`related`、`tags`、`credits`、`rating`、`access` 等变量。常用字段可直接输出：

```html
<h1>{$vod.vod_name}</h1>
<p>{$vod.vod_year} · {$vod.vod_area} · {$vod.vod_language}</p>
<p>主演：{$vod.vod_actor|default='暂无'}</p>
<p>导演：{$vod.vod_director|default='暂无'}</p>
<p>{$vod.vod_content|strip_tags}</p>
{notempty name="vod.vod_douban_id"}<p>豆瓣 ID：{$vod.vod_douban_id}</p>{/notempty}
{notempty name="vod.vod_imdb_id"}<p>IMDb ID：{$vod.vod_imdb_id}</p>{/notempty}

{if !empty($access.allowed)}
  {volist name="sources" id="source" key="sourceIndex"}
    <h2>{$source.name}</h2>
    {volist name="source.episodes" id="episode" key="episodeIndex"}
      <a href="{:htmlentities(ff_play_url($vod.vod_id,$sourceIndex-1,$episodeIndex-1))}">{$episode.title}</a>
    {/volist}
  {/volist}
{else /}
  <p>此视频需满足观看权限后才能播放。</p>
{/if}
```

`ff_play_url(影片ID, 线路下标, 分集下标)` 的**函数参数从 0 开始**；生成的公开 URL 中线路和分集**从 1 开始**。例如 `ff_play_url(16,0,0)` 对应第一条线路的第一集。模板里的 `{volist ... key="sourceIndex"}` 从 1 开始，所以调用时要减 1。不要自己拼接 `/play/...`，后台修改 URL 规则后函数仍能生成正确链接。权限判断不能只靠模板隐藏按钮，服务端播放页仍会校验权限。

播放页 `vod/play.tpl` 已提供 `currentSource`、`current`、`source`、`episode`、`sources`、`sid`、`pid`、`prevUrl`、`nextUrl` 和播放器所需参数。没有 `access` 页面变量：服务端在进入播放模板前已经校验观看权限，无权观看时返回 403。直接参考 MXOne 播放页的 `data-ff-player` 容器及 `/theme-assets/shared/player/player.js` 引用；仅输出远程地址不等同于支持 HLS、解析和弹幕。

### 播放器与远程弹幕

以下容器放在 `vod/play.tpl` 中，样式由自己的 CSS 控制。先引入 MXOne 播放页使用的 HLS、ArtPlayer 和弹幕组件，再加载 `/theme-assets/shared/player/player.js`。建议复制默认播放页的资源引用，避免漏掉依赖。

```html
<div class="my-player" data-ff-player
     data-url="{$current.url}"
     data-type="{$currentSource.code}"
     data-title="{$vod.vod_name} {$current.title}"
     data-media-id="{$vod.vod_id}"
     data-episode-id="{$episode.id}"
     data-video-id="{$danmuVideoId}"
     data-parse-api="/danmu/parse"
     data-remote-danmu-api="{if !empty($danmakuEnabled)}/danmu/remote{/if}"
     data-danmu-read-api="{if !empty($danmakuEnabled)}/danmu/read{/if}"
     data-danmu-send-api="{if !empty($danmakuEnabled)}/danmu/send{/if}"
     data-force-parser="{$playerForceParser}"
     data-autoplay="{$playerAutoplay}"
     data-auto-next="{$playerAutoNext}"
     data-next-url="{$nextUrl}"></div>
```

`episode.id` 是数据库分集 ID，不能用 `pid`（播放序号）代替。解析与远程弹幕请求必须带本地影片 ID、分集 ID，服务端会校验播放器、发布状态和观看权限；不要让模板把任意第三方地址直接交给解析接口。

播放器按“解析器 URL”决定工作方式：填写后，所有播放地址或资源标识均原样作为参数传给该接口（包括带 `.m3u8` 或 `.mp4` 后缀的地址）；留空则直接播放，不会自动使用全局默认解析地址。解析域名必须逐个加入白名单，不支持通配符。资源标识只是接口参数，程序不会把它当作网址直接请求。

直链支持 `m3u8`、`mp4`、`webm`、`ogg`，带扩展名时自动识别；无扩展名时默认 `m3u8`，可将 `direct_type` 改为 `mp4`。新增播放器和编辑空配置时会显示以下可用示例，不会自动覆盖已保存的非空配置：

```json
{
    "parser_mode": "json",
    "direct_type": "m3u8"
}
```

- JSON 模式：解析接口收到 GET 参数 `url`，返回 `{"code":200,"data":{"url":"https://媒体域名/video.m3u8","type":"m3u8"}}`，或直接返回 `{"url":"…","type":"mp4"}`。
- `type` 应填写媒体格式，也支持 `hls`、`video/mp4` 等常见 MIME 类型。如果上游使用“单线程”等非媒体描述，会改用返回地址的扩展名识别；无扩展名时须返回明确的媒体类型。
- iframe 模式：接口是播放器网页，接收 GET 参数 `url`，例如 `https://解析域名/player?url=…`。也可在解析地址中使用 `{url}` 占位符。iframe 内的选集、弹幕等功能由解析站自身提供。
- 网页解析播放器可将 `parser_mode` 改为 `iframe`。不再需要配置 `force_parser`，填写解析器 URL 就会调用解析。

远程弹幕 API 收到 GET 参数 `title`（片名）和 `episode`（集号），返回 `{"code":0,"data":[{"text":"弹幕内容","time":12.5,"mode":0,"color":"#FFFFFF"}]}`。配置了 Token 时使用 `Authorization: Bearer …`；也兼容 `danmaku`／`danmuku` 数组及 `[时间,模式,颜色,文本]`、`[时间,模式,颜色,用户,文本]` 格式，颜色可为十六进制字符串或 RGB 整数。`mode` 为 `0/1/2`（滚动/顶部/底部）。匹配接口可返回 `{"danmaku_url":"https://同一弹幕域名/具体地址"}`，仅接受与配置 API 同源的地址。若响应包含 `code`，仅 `0`／`200` 表示成功；鉴权失败等错误不得返回成功代码。

解析和弹幕接口必须是可访问的公网 HTTP/HTTPS 地址，不能指向内网、回环地址或重定向；失败会显示服务异常，不会伪装成成功。服务端有超时、响应大小、弹幕数量与缓存限制，在后台按需调整。未启用远程弹幕时仍可使用本站弹幕。

程序不捆绑第三方解析／弹幕账号。启用前请先取得可用 API 和必要授权，再填写后台“系统 → 独立播放器”。没有服务时保持远程弹幕关闭，直链仍可正常播放。

依赖的先后顺序为 ArtPlayer、HLS、弹幕插件、程序播放器 JS；均已随程序提供，不需要新手另找 CDN。按以下顺序使用 `defer`，或整体保留默认页头的播放器加载段，二者不能重复加载：

```html
<script src="/player/vendor/artplayer.js" defer></script>
<script src="/player/vendor/hls.min.js" defer></script>
<script src="/player/vendor/artplayer-plugin-danmuku.js" defer></script>
<script src="/theme-assets/shared/player/player.js" defer></script>
```

播放器容器需有尺寸，例如添加 `.my-player { width:100%;aspect-ratio:16/9;background:#000; }`。发送弹幕需要页头的 `csrf-token`。`sid`／`pid` 是当前线路／分集的 0 基位置，`source.id`／`episode.id` 才是持久数据库 ID；排序或停用可能改变位置，不要用播放序号关联附件和记录。

```html
{notempty name="prevUrl"}<a href="{$prevUrl}">上一集</a>{/notempty}
{notempty name="nextUrl"}<a href="{$nextUrl}">下一集</a>{/notempty}
```

受限下载附件使用详情页已经过滤的 `assets`，不要再从数据库查询全部附件把受限地址重新输出。附件字段为 `id`、`asset_type`、`label`、`url`、`language` 等：

```html
{volist name="assets" id="asset"}
  <a href="{$asset.url}" target="_blank" rel="noopener noreferrer">
    {$asset.label|default=$asset.asset_type}
  </a>
{/volist}
```

分集剧情存放于独立表，详情页可用 `scenarios` 和 `scenarioCount`；完整剧情页为 `/vod/{影片ID}/scenarios`，单集链接请用 `ff_url('scenario',剧情ID)`：

```html
{notempty name="scenarios"}
  {volist name="scenarios" id="scenario"}
    <a href="{:htmlentities(ff_url('scenario',$scenario.id))}">第 {$scenario.episode_no} 集 · {$scenario.title}</a>
  {/volist}
{/notempty}
```

需要从其他页面查询某部影片的剧情时，可以使用 `ff_mysql_scenario('vodid:16;limit:30')`；`vodid` 是本地影片 ID，不是来源站的远程 ID。

### 剧情标签说明

`ff_mysql_scenario()` 适用于各前台模板，按后台排序、集号、ID 升序返回已发布未归档剧情。

| 参数 | 含义 |
| --- | --- |
| `vodid` | 本地影片 ID，可多个，推荐这个名称 |
| `cid` | 影片 ID 的别名，**不是分类 ID** |
| `id` | 剧情记录 ID，可多个 |
| `limit` | 默认 100，上限 200，不自动分页 |

```html
{volist name=":ff_mysql_scenario('vodid:16;limit:30')" id="chapter"}
  <article>
    <h3><a href="{$chapter.scenario_link}">第 {$chapter.scenario_pid} 集 · {$chapter.scenario_name}</a></h3>
    <p>{$chapter.scenario_content|strip_tags}</p>
  </article>
{/volist}
```

返回原始字段 `id`、`media_id`、`episode_no`、`title`、`content`，并附加 `scenario_id`、`scenario_vid`、`scenario_pid`、`scenario_name`、`scenario_content`、`scenario_link`。未指定影片时会混合多部影片，制作一部剧的目录时务必传 `vodid`。

详情页 `scenarios` 只先取最多 6 条预览；完整列表页 `vod/scenarios.tpl` 有该影片所有已发布剧情。控制器传入的剧情使用原始字段，不保证带上述查询附加别名。完整目录入口可用 `ff_url('vod/juqing',影片ID)`；单集 `vod/scenario.tpl` 这样展示：

```html
<h1>{$vod.vod_name} · 第 {$scenario.episode_no} 集</h1>
<h2>{$scenario.title}</h2>
<p>{$scenario.content|strip_tags}</p>
{notempty name="previous"}<a href="{:htmlentities(ff_url('scenario',$previous.id))}">上一集剧情</a>{/notempty}
{notempty name="next"}<a href="{:htmlentities(ff_url('scenario',$next.id))}">下一集剧情</a>{/notempty}
```

评论示例：`ff_mysql_forum('cid:16;limit:10')` 取影片 16 的已审核评论；`ff_mysql_forum('target:site;limit:10')` 取站点留言。输出评论内容时保持变量的默认 HTML 转义，不要对用户内容使用 `raw`。

### 图片地址与防盗链代理

在后台“系统 → 附件设置 → 图片代理”填写外部代理前缀，例如 `https://example.com/img.php?url=`；“防盗链域名”每行填写一个域名，例如 `doubanio.com`，也会匹配 `img1.doubanio.com` 等子域名。域名留空则不使用外部代理。

`vod_pic`、`news_pic`、`person_pic`、专题封面、公共轮播和友情链接图片会自动应用配置，模板照常输出即可：

```html
<img src="{$vod.vod_pic}" alt="{$vod.vod_name}">
```

自定义数据里的原始图片地址可以使用 `ff_url_img()`：

```html
<img src="{$customImage|ff_url_img}" alt="">
```

默认模板引擎会在输出时自动进行 HTML 转义，不需要重复追加 `htmlentities`。

程序只在展示时转换，不改数据库中的原图地址，也不改采集输出 API 的原图地址。本地图片、未匹配域名及已经加过代理的地址不会再次追加代理。原图地址整体进行 URL 编码，避免原图的 `&` 等参数被代理接口误解析；代理服务应读取 URL 解码后的 `url` 参数。复杂代理地址可以用 `{url}` 指定编码后原图的位置。

外部代理服务需要由站长配置并保证可访问；此设置不会自动部署图片代理服务。

循环写 `item.字段`，详情／播放写 `vod.字段`；记录变量可自定义，但字段名不能随意改。

| 字段 | 当前含义 |

| `vod_year`、`vod_area`、`vod_language` | 年份、地区、对白语言 |
| `vod_continu` | 原始连载／清晰度说明，不保证是数字 |
| `remark_text` | 展示更新说明；为空时按完结状态显示“已完结”或“更新中” |

## 6. 链接、分页与排错

- 详情/分类/资讯/专题/人物：分别用 `ff_url('vod',ID)`、`ff_url('type',ID)`、`ff_url('news',ID)`、`ff_url('special',ID)`、`ff_url('person',ID)`。
- 搜索表单：`<form action="{:htmlentities(ff_url('search'))}" method="get"><input name="wd"><button>搜索</button></form>`。不要把关键词未经编码直接拼进 URL。
- 分类、资讯等分页：控制器已传 `pager`，可用 `<div class="pager">{$pager|raw}</div>`。只有这个由分页器生成的 HTML 才直接输出 `raw`。
- 模板不出现在后台：检查第 1 节的八个必需文件、目录名和文件权限。
- 页面仍像 MXOne：检查后台选中的主／移动模板、主题内相对 include 和 `ff_theme_asset()` 引用，确认修改的是 `public/theme-assets/` 下对应主题的资源；清理模板缓存。
- 查询为空：确认内容已发布、分类 ID 正确、图片/线路有数据；`ff_mysql_*` 默认只取已发布或已启用内容，不要为了展示草稿在公开页面使用 `status:all`。
- 详情能打开而播放 404：确认该影片有播放线路与分集，并用 `ff_play_url()` 生成链接。
- CSS 改了不生效：清理浏览器缓存或给自己的 CSS URL 添加版本参数；不要为了改颜色去修改数据标签。

完整页面与样式可对照 `view/mxone/`；`/features` 展示当前站点真实数据和调用示例。建议先做出一个可用的首页和影片卡片，再依次替换分类、详情、播放和其他页面。

### URL 函数速查

| 页面 | 推荐写法 |
| --- | --- |
| 首页 | `ff_url('home')` |
| 分类、详情 | `ff_url('type',分类ID)`、`ff_url('vod',影片ID)` |
| 选集 | `ff_play_url(影片ID,0基线路位置,0基分集位置)` |
| 视频评论、剧情目录 | `ff_url('comments',影片ID)`、`ff_url('vod/juqing',影片ID)` |
| 单集剧情 | `ff_url('scenario',剧情记录ID)` |
| 资讯、专题、人物、角色详情 | `ff_url('news',ID)`、`ff_url('special',ID)`、`ff_url('person',ID)`、`ff_url('role',ID)` |
| 搜索 | `ff_url('search',['wd'=>关键词,'pg'=>页码])` |
| 最近更新、热播、地图、RSS | `ff_url('latest')`、`ff_url('hot')`、`ff_url('map')`、`ff_url('rss')` |
| 登录、注册、会员中心 | `ff_url('user/login')`、`ff_url('user/register')`、`ff_url('user/center')` |
| 留言、VIP、充值、功能示例 | `ff_url('guestbook')`、`ff_url('vip')`、`ff_url('payment')`、`ff_url('features')` |

生成含筛选的分类链接可传数组：`ff_url('type',['id'=>1,'area'=>'中国大陆','year'=>2026])`。`ff_url()` 第三个参数 `false` 表示不附加配置的 HTML 后缀，不会改变权限。生成函数返回的具体地址取决于后台规则，不要按默认地址写死模板。

当前程序还提供下列带分类上下文的 URL 方法，新模板通常只需上述简写：

```php
ff_url_read_vod($listId, $listDir, $vodId, $ename = '', $jump = '', $suffix = true)
ff_url_read_news($listId, $listDir, $newsId, $ename = '', $jump = '', $page = 1, $suffix = true)
ff_url_read_special($listId, $listDir, $specialId, $ename = '', $suffix = true)
ff_url_read_star($listId, $listDir, $personId, $ename = '', $suffix = true)
ff_url_read_role($listId, $listDir, $personId, $ename = '', $suffix = true)
ff_url_play($listId, $listDir, $vodId, $ename = '', $sid = 0, $pid = 0, $suffix = true)
```

`ff_url_vod_read()`、`ff_url_vod_play()` 是视频详情／播放方法别名。`ff_url_play()` 的线路、分集也从 0 开始。视频／资讯方法的非空 `jump` 直接返回该地址，不可将它们当成任意 URL 的安全清理器。

## 7. 分类筛选与搜索完整示例

### 分类页 `vod/type.tpl`

使用控制器提供的 `vods`，不能另查固定第一页后忽略筛选。这里直接展示文字链接，之后可替换成自己的卡片组件。

```html
<h1>{$type.type_name}（{$vodTotal} 部）</h1>
<form action="{:htmlentities(ff_url('type',$type.type_id))}" method="get">
  <label>地区 <input name="area" value="{$filters.area}"></label>
  <label>年份 <input name="year" value="{$filters.year}"></label>
  <label>语言 <input name="language" value="{$filters.language}"></label>
  <label>类型 <input name="type" value="{$filters.type}"></label>
  <label>排序 <select name="order">
    <option value="addtime" {if $filters.order=='addtime'}selected{/if}>最新</option>
    <option value="hits" {if $filters.order=='hits'}selected{/if}>人气</option>
    <option value="gold" {if $filters.order=='gold'}selected{/if}>评分</option>
  </select></label>
  <button type="submit">筛选</button>
</form>
{volist name="vods" id="item"}
  <a href="{:htmlentities(ff_url('vod',$item.vod_id))}">{$item.vod_name}</a>
{/volist}
{empty name="vods"}<p>没有符合条件的视频。</p>{/empty}
<nav aria-label="分页">{$pager|raw}</nav>
```

可把输入框改成遍历 `filterOptions.area/year/language/type` 的下拉框。实际执行的筛选为 `type`、`area`、`year`、`language`；排序为 `addtime`、`hits`、`gold`、`id`。后台筛选配置还可能包含其他键，但当前分类控制器未实现的条件不能只画出按钮就称为功能可用。

分类、资讯等页的 `pager` 由程序生成并保留查询参数，不必自己拼分类页码。

### 搜索页 `search/index.tpl`

```html
<form action="{:htmlentities(ff_url('search'))}" method="get">
  <input name="wd" value="{$keyword}" aria-label="搜索关键词">
  <button type="submit">搜索</button>
</form>
<p>{$keyword} · 共 {$total} 部</p>
{notempty name="message"}<p>{$message}</p>{/notempty}
{volist name="vods" id="item"}
  <a href="{:htmlentities(ff_url('vod',$item.vod_id))}">{$item.vod_name}</a>
{/volist}
{if $pages > 1}
  <nav aria-label="搜索分页">
    {if $page > 1}<a href="{:htmlentities(ff_url('search',['wd'=>$keyword,'pg'=>$page-1]))}">上一页</a>{/if}
    <span>第 {$page} / {$pages} 页</span>
    {if $page < $pages}<a href="{:htmlentities(ff_url('search',['wd'=>$keyword,'pg'=>$page+1]))}">下一页</a>{/if}
  </nav>
{/if}
```

当前搜索支持 `wd`、`pg`（兼容 `p`），不支持独立的分类 `cid`、排序 `order` 筛选。不同搜索驱动的匹配、排序可能不同；`ff_mysql_vod('wd:...')` 只查片名，不代替前台搜索。没有结果和没有输入关键词时用 `message` 显示对应提示。

## 8. 评论、会员与互动接入

### 评论标签 `ff_mysql_forum()`

适用于各前台模板，按创建时间、ID 降序取已审核未归档记录。列表是平面记录，可能含回复，不自动生成回复树或分页。

| 参数 | 含义 |
| --- | --- |
| `target` | `media` 默认视频评论，`site` 站点留言 |
| `cid` | 本地影片 ID，不是分类 ID；视频评论时使用 |
| `limit` | 默认 30，上限 200 |

```html
{volist name=":ff_mysql_forum('target:media;cid:16;limit:10')" id="comment"}
  <article>
    <strong>{$comment.forum_name}</strong>
    <p>{$comment.forum_content}</p>
    <time>{$comment.forum_addtime|date='Y-m-d H:i'}</time>
  </article>
{/volist}
```

字段：`forum_id`、`forum_cid`、`forum_pid`（父评论 ID）、`forum_title`、`forum_content`、`forum_name`、`forum_addtime`（时间戳）。查询标签只读，不处理提交；详情的 `commentHtml` 是程序转义后生成的 HTML，可用 `raw` 输出。

### 发布评论

用于视频详情／完整评论页，按 `commentsEnabled`、`commentLoginRequired`、`isLoggedIn` 决定界面。服务端仍执行游客开关、审核、禁言、敏感词和频率规则。

```html
{if $commentsEnabled}
  <form method="post" action="/forum/post">
    <input type="hidden" name="_token" value="{$csrf}">
    <input type="hidden" name="cid" value="{$vod.vod_id}">
    <input type="hidden" name="pid" value="0">
    <label>评论内容 <textarea name="content" rows="4" required></textarea></label>
    <button type="submit">发表评论</button>
  </form>
{/if}
```

`pid=0` 是主评论，回复时传父评论 ID。基础表单使用正常 POST；需要 AJAX／登录弹窗时整体保留默认 `.mx-comment-editor`、`data-comment-login-required`、`data-user-logged` 和 `common/comment_login_modal.tpl`。留言板则 POST `/guestbook`，传 `content`、`_token`，使用自己的 `items`、回复与 `pager`；不要误接成视频评论。

### 评分、顶踩、收藏与记录

互动依赖 `/static/js/mxone.js`，与播放器 JS 是两个文件。需要页头的 `csrf-token`；不要重复加载 JS。

```html
<button type="button" data-vod-updown data-id="{$vod.vod_id}" data-type="up">顶 <em data-up-count>{$vod.vod_up}</em></button>
<button type="button" data-vod-updown data-id="{$vod.vod_id}" data-type="down">踩 <em data-down-count>{$vod.vod_down}</em></button>
<button type="button" data-vod-favorite data-id="{$vod.vod_id}" data-api="/user/favorite?" data-login-url="/user/login">收藏</button>
<script src="/static/js/mxone.js" defer></script>
```

| 功能 | 接口与字段 | 默认模板接入 |
| --- | --- | --- |
| 评分 | POST `/vod/rate`：`id`、`score`、`_token` | `data-vod-rating`，星层、`data-rating-stars`、计分文字须整体保留 |
| 顶／踩 | POST `/vod/vote`：`id`、`type=up/down`、`_token` | `data-vod-updown` |
| 收藏 | GET `/user/favorite?id=...` 查询；POST 同路径：`id`、`_token` 切换 | `data-vod-favorite`，需有效登录 |
| 观看记录 | POST `/user/history`：`id`、`episode_id`、`_token` | 播放页 `data-mx-history-item`，`episode_id` 是数据库 ID |
| 积分解锁 | POST `/vod/unlock`：`id`、`_token` | 详情页按 `access` 输出表单 |
| 卡密充值 | POST `/user/redeem`：`card_number`、`_token` | `page/payment.tpl`，需登录和管理员发放的有效卡密 |

观看记录容器还保留 `data-vod-id`、`data-episode-id`、`data-vod-name`、`data-episode-title`。游客的本地观看记录与登录会员的服务端记录不是同一份数据。

选集折叠、倒序需保留 `data-episode-source`、`data-episode-list`、每集的 `data-episode-index` 及按钮 `data-episode-sort-toggle`。倒序只变展示顺序，不重新计算已经生成的链接。完整结构见默认播放页。

会员页从 `view/mxone/user/` 复制完整表单再改样式。登录字段为 `user_name`、`user_pwd`、`redirect`、`_token`；注册另有 `user_email`。中心的 `user.user_score` 是积分，`user.user_deadtime` 是到期时间戳，`records` 是记录列表，`favorites` 为分页收藏，`favoritePager` 输出分页。普通首页没有 `user` 变量，模板或 JS 不能自行生成登录状态或修改积分。

## 9. 标签适用范围与安全

- 本文只列 FeiFeiCMS 8.5 已提供的方法和字段。参数以各函数的参数表为准，不套用参考文档的标签或参数。
- 同名 `cid` 在视频／资讯／专题查询中指分类，在剧情／评论查询中指影片；同名 `id` 指对应模型的记录，必须先确认所在模块。
- 列表函数取数据，组件决定展示，JS 负责交互，控制器执行权限和写入；只画出按钮或改一个变量不能增加服务端功能。
- 页面变量与查询附加字段不是一回事。按第 5 节页面合同输出，缺失时先核对所在页面，不盲目给变量补空值掩盖问题。
- 公开模板保持发布／启用过滤，不使用 `status:all`。限制条数、避免循环内重复查询，分页使用现有控制器。
- 模板编辑权限仅交给可信管理员；不存密钥、不拼任意 SQL、不公开模板文件、不把用户内容 `raw` 输出。
- 区分编译模板缓存、数据缓存、浏览器／CDN 缓存，针对实际层清理，不盲目删除 `runtime/`。
- 网站报错时用后台健康检查及受保护日志定位，不在公开环境开启调试输出堆栈、数据库配置或密钥。

## 10. 制作完成后的验收清单

- 首页／分类／搜索：有数据、无数据、长片名、无封面、中文特殊字符、真实翻页与组合筛选。
- 详情：副标题、主演、导演、关键词、日期、豆瓣／IMDb、剧情、附件、人物关联和无线路状态。
- 播放：第一／最后一集、多线路、倒序、折叠、前后集；函数生成的公开线路与分集从 1 开始。
- 权限：游客、普通会员、有效／过期 VIP、积分解锁前后，不能只验证按钮隐藏。
- 互动：评分、顶踩、收藏、记录、评论、回复、需登录、待审核和限流状态。
- 扩展：资讯、专题及关联影片、人物和角色、留言回复、会员、VIP、充值、地图、RSS。
- 样式：手机／平板／电脑，键盘焦点、表单标签、图片替代文字、空列表占位。
- 资源：本地 CSS／JS 没有 404，不重复加载脚本，模板源文件无法访问／下载。
- URL：后台换规则后，导航、详情、选集、剧情、搜索仍通过程序方法生成正确链接。

外部播放、解析、远程弹幕等需在自己的服务配置和授权下单独联调。模板能渲染不代表外部服务已验收。发布模板时只提供模板与所需静态资源，不附 `.env`、数据库、用户数据和第三方账号。
