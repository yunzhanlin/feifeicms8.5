# 第二阶段优化与验收

日期：2026-09-30

## 已完成

- 采集 HTTP 响应在传输过程中限制为 5 MiB，不再等待整个超大响应进入内存后才拒绝。
- 采集任务用 `queued -> running` 条件更新原子领取，避免多工作进程重复执行。
- 观看记录一次批量读取影片、线路和分集顺序，取消逐条 N+1 查询。
- 登录与注册限流同时写入缓存和本地持久状态，Redis 短暂不可用时不会退化为无限尝试。
- 管理员和会员登录成功后重生会话 ID；Cookie 默认启用 `HttpOnly` 和 `SameSite=Lax`，HTTPS 安装时自动启用 `Secure`。
- 健康检查对外只返回健康状态，内部错误仅写服务端日志，并使用 10 秒短缓存防止高频探测压力。
- `ffx_media` 新增四个 JSON 生成列和管理列表索引，常用星期、状态、系列与录入人筛选不再对整表反复执行 JSON 解析。
- 增加 `feifei:schema:upgrade`，根据 `ffx_schema_versions` 执行增量 SQL，并用 MySQL advisory lock 防止并发升级。
- 安装器引入进程互斥和空库失败回滚；数据库备份改为无缓冲流式导出，恢复前先流式校验语句白名单。
- 兼容采集 API 支持 ETag/304 和 15 秒客户端缓存；Nginx 静态文件设置 7 天缓存。
- GitHub Actions 覆盖 PHP 8.2、8.3、8.4、8.5，另有 MySQL 8.4 + Redis 8.2 集成作业与 Composer 安全审计。

## 实机验收

- 本地面板：PHP 8.5.10、MySQL 8.4.11、Redis 8.2.10、Meilisearch 1.53.2。
- 结构从版本 11 升级至 12，重复执行升级命令会正确报告已是最新版。
- PHPUnit：79 项测试、663 个断言，实机 MySQL 集成用例全部通过。
- PHP 8.2、8.3、8.4、8.5 容器矩阵：79 项测试全部通过（无 MySQL 的矩阵作业跳过 2 项集成用例）。
- 真实 HTTP 后台验收覆盖分类、影片、线路/分集、文章/专题/人物、用户、运营、标签、定时任务、卡密、上传、静态生成、缓存清理、数据库备份/恢复/删除，全部通过，验收数据已清理。
- `/health` 返回 200 与最小化 JSON；VOD API 首次返回 ETag，带 `If-None-Match` 再请求返回 304。
- 管理员登录前后会话 ID 已确认变更，响应 Cookie 包含 `HttpOnly; SameSite=lax`。
- Nginx 配置检查通过，CSS/图片/字体等静态资源返回 7 天 `Expires`/`Cache-Control`。
