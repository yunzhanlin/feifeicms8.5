# 后台系统设置导航去重核对

- 核对日期：2026-09-29
- 核对环境：本地宝塔站点 `http://feifeicms-modern.localhost:19101`
- 问题：同一组系统设置功能同时在左侧竖向导航和内容区顶部横向导航重复显示。

## 修复结果

- 保留 FeiFeiCMS 原版的左侧竖向系统设置菜单。
- 删除内容区顶部重复的全量横向菜单。
- 内容区顶部只显示当前页标题，例如“全局配置”、“付费点播”、“URL优化、伪静态配置”。
- 共享设置模板修复会覆盖全局配置、付费点播、播放来源、独立播放器、内容、缓存、采集、附件、邮件、注册、评论和微信设置页。

## 现场验证

1. `/admin/settings/base`：左侧菜单保留，内容区只显示“全局配置”标题。
2. `/admin/settings/pay`：左侧菜单保留，内容区只显示“付费点播”标题和对应表单。
3. `/admin/settings/rewrite`：左侧菜单保留，内容区只显示“URL优化、伪静态配置”和路由字段。
4. 已清理 ThinkPHP 运行缓存，后台 CSS 版本提升为 `v=27`，避免浏览器继续使用旧样式。
5. PHPUnit：45 个测试全部通过，344 个断言通过。

## 可用性结论

去除重复导航后，页面层级与 FeiFeiCMS 原版一致，同时减少了键盘 Tab 遍历时的重复链接。本次核对不代表已完成全站无障碍认证。
