# URL 自定义规则验收（2026-09-29）

## 实现范围

- 完整内置 FeiFeiCMS 7.4 的 27 条默认规则。
- 支持 `(:num)`、`(:letter)`、`(:letternum)`、`(:any)`，按类型和出现顺序双向替换。
- 支持空行、`#`/`//` 注释、第三段固定参数。
- 保存前检查格式、非法字符、路径穿越、外部协议、占位符错配、来源和目标重复。
- 前台模板链接生成与入站路由使用同一套编译结果，支持 1–8 段自定义路径。
- 覆盖分类及分页、视频详情及播放、文章及分页、专题、人物、角色、留言、评论、用户、分集剧情和视频扩展页面。
- 后台提供双向规则验证及 27 条编译预览；验证不会保存。
- 规则为空时自动关闭 URL 自定义开关，避免开启空路由造成全站 404。
- 后缀支持 `.html`、`.htm`、`.shtml`、`.shtm` 和无后缀，并严格拒绝不符合当前配置的后缀。

## 自动化验证

- PHP 8.5.10：65 tests / 598 assertions 通过。
- 27 条 7.4 规则全部完成编译，代表规则均完成生成与反向解析测试。
- 非法占位符类型/顺序、重复规则、路径穿越、外部协议和错误 action 均被拒绝。
