# 程序使用量与版本统计

FeiFeiCMS 在安装完成后，通过网站请求结束阶段发送匿名心跳。成功上报后 24 小时内不会重复发送；失败会退避重试，连接和总请求分别限制为 1.5 / 4 秒，错误不会变成网站错误页面。PHP-FPM 在响应完成后执行；其他 SAPI 的请求收尾阶段可能最多增加 4 秒。健康检查和安装页面不触发心跳。

默认接收地址为 `https://tj.shankan.cc/v1/heartbeat`。站点后台不新增统计菜单、页面或提示，也不往前台模板插入统计代码。统计行为在本文和发布说明中说明。

## 发送的信息

固定字段只有协议版本、随机安装 ID、程序版本、触发来源（网页 / 计划任务）。默认附带 PHP 主次版本，例如 `8.5`。不发送域名、站名、网址、站长信息、账号、密码、数据库连接、内容数据或访客行为。

安装 ID 是随机 UUID v4，保存在本站数据库 `ffx_site_settings` 的非公开项 `internal.usage_reporting.v1` 中，与域名或 IP 无关。该项同时记录最近上报成功时间和下次尝试时间。更新、清理缓存或修改域名不会重置 ID。完整复制数据库会沿用 ID；不同站点如要独立计数，应使用独立安装数据库。不要把首次收到心跳的时间当作真实安装日期。

## 关闭或调整

在本站 `.env` 中添加以下设置可完全关闭后续上报：

```dotenv
USAGE_REPORTING=false
```

只关闭 PHP 版本信息：

```dotenv
USAGE_ENVIRONMENT=false
```

部署者有自己的统计服务时，可显式设置 `USAGE_ENDPOINT=https://自己的接收地址/v1/heartbeat`。公网接收地址必须使用 HTTPS；仅本机测试允许回环 HTTP 地址。不跟随跳转，也不关闭 TLS 验证。

关闭上报不会删除接收端已有的匿名累计记录；长时间不再上报的实例会自然退出近 7 / 30 天活跃统计。已有版本未包含本功能，历史使用量无法补齐。

## 无人访问时的心跳

没有网页请求就不会触发网页心跳。需要了解程序是否持续运行，可由本站计划任务定期执行（将路径替换为本站实际值）：

```cron
17 * * * * cd /www/wwwroot/example && /www/server/php/85/bin/php think feifei:usage:report >/dev/null 2>&1
```

即使每小时执行，也由同一套数据库状态保证成功后 24 小时不重复上报。命令会输出 `sent`、`not_due`、`disabled` 等状态，排查时可手动执行一次；失败不会输出请求载荷或任何凭据。

## 汇总面板

管理面板只向程序维护者显示累计使用实例、近 7 / 30 天活跃、近 7 天新增、每日活跃趋势和版本分布。一个人可以有多个安装，因此实例数不等于独立人数；活跃表示近期收到网站或计划任务心跳，不表示统计到了真实访客。

接收端 Docker、一键启动、HTTPS 代理、私有登录信息及备份方法见 [接收端部署说明](https://github.com/yunzhanlin/feifeicms8.5/blob/main/deploy/usage-statistics/README.md)。接收端不包含在 CMS 完整安装包或更新包中；站长无须部署接收服务。

本功能只增加程序代码，更新包不需要覆盖模板、样式、`.env` 或网站配置。
