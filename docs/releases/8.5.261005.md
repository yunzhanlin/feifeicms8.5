# FeiFeiCMS 8.5.261005 正式版

发布日期：2026-10-05。由 [8.5.261004.3](8.5.261004.3.md) 升级。

## 新增

- 数据库管理增加“字段内容替换”，沿用 4.3 的选表、选字段、原文、新文和替换条件操作方式。
- 支持文本与 JSON 内容、匹配数量与样例预览、条件筛选和删除指定文字；每次最多替换 50000 条。
- 替换需要超级管理员权限、预览和确认；整批事务回滚、重复提交保护、操作记录和前台缓存清理。
- 提供 Apache 安全站点配置，配合 Nginx／宝塔规则保护模板和其他私有文件。

## 更新与修复

- 后台旧“工具／数据替换”地址转到数据库管理，统一使用预览与确认流程。
- 加强后台路由权限检查与模板目录、编码路径和软链接访问防护；后台模板编辑仍供超级管理员使用。
- 数据库备份保留生成字段定义、时间默认值和触发器，并使用跨表一致性快照。
- 修复计划采集并发排队和更新任务状态竞争；标签使用次数改为分组统计。
- 发布包只提供默认 MXOne、后台和安装模板，不捆绑本地额外模板。

## 删除与兼容变化

- 移除未使用的前台模板副本、公开截图对比页和仓库中的 4.3 参考程序；保留 4.3 单文件升级插件。
- 不删除业务数据，不新增数据库表；支持 PHP 8.2～8.5、MySQL 5.7.13+ 和 8.x。
- 替换不能修改主键、数字、日期、生成字段、密码或系统／权限／账务／任务表；请使用对应管理功能。

## 升级说明

1. 备份数据库、`.env`、上传文件和自定义模板。
2. 在“工具 → 版本升级”检查并确认更新，或手动覆盖程序并执行 `php think feifei:schema:upgrade`。
3. 网站运行目录必须指向 `public/`；按照 `deploy/baota/thinkphp.conf` 或 `deploy/apache/feifeicms.conf` 核对私有目录与软链接保护。程序更新不能代替 Web 服务器配置。
4. 已生成的静态页面需要重新生成；MySQL 搜索立即读取新数据，外部搜索由 `php think feifei:search:sync` 同步。
