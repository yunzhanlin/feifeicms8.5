# FeiFeiCMS 8.5.261003 Beta2.1

发布日期：2026-10-03。此版是 [8.5.261003 Beta2](8.5.261003-beta2.md) 的兼容修订版；保留原 Beta2 标签和安装包，以便已安装站点识别新版本。

## 新增

- 单文件旧站升级插件 `feifeicms43-upgrade-v1.0.0.php`：放到 FeiFeiCMS 4.3 网站根目录，登录旧站后台后通过浏览器预检、分批迁移到独立安装的 8.5 站点；支持中断续跑、错误批次重试和完成后搜索同步。
- Release 同时提供旧站插件文件及其 SHA-256 校验文件。插件使用说明见 [插件文档](../../plugins/legacy43/README.md)。

## 更新与优化

- 新版数据库支持 MySQL 5.7.13+ 和 8.x：安装器、结构安装与升级命令使用统一版本检查；建库和建表改用两代都支持的 `utf8mb4_unicode_ci`，表结构显式使用 InnoDB `DYNAMIC` 行格式。
- 旧站插件重新校验管理员密码并使用 CSRF 令牌；旧库密码通过进程环境变量传递，不写入 URL 或命令行参数。目标命令仅继承必要环境变量，避免旧站的 `DB_*` 配置覆盖新站数据库。
- 迁移命令新增单批 JSON 模式、预检和结束同步入口，既服务旧站插件，也可用于其他批处理调用。

## 删除与兼容变化

- 未删除业务功能或数据表。MySQL 5.5/5.6 不在兼容范围，MariaDB 未经过本次兼容验证；MySQL 8.4 仍是推荐新部署版本。
- 旧站插件只迁移数据库业务数据，不原地替换 4.3 程序、上传附件、模板或服务器配置；验收后需自行切换站点入口并删除旧站插件文件。

## 升级注意

- 已安装 Beta2 的站点应升级到本版；本版采用更高版本号，因此可被后台更新检测识别。
- 使用旧站插件前，先在独立目录安装 8.5，备份新旧数据库，并暂停旧站写入。旧站 PHP 需为 7.4+ 且允许 `proc_open`，新站 PHP CLI 需为 8.2～8.5。
