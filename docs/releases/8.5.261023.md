# FeiFeiCMS 8.5.261023

发布日期：2026-10-23。

## 更新

- 修复资源库分类建议被误显示为已绑定、未绑定资源默认入库到电影的问题；页面直接显示已保存的本地分类名称。
- 分类绑定分开保存并加锁合并，避免同时修改不同远程分类时互相覆盖；本地分类已停用或删除时跳过采集。
- 修改分类绑定后，重新采集同来源影片会同步修正主分类和主分类关联，不重建影片、线路或分集；已锁定影片仍跳过。
- 不再跨不同根分类合并仅豆瓣／IMDb编号相同的影片，避免电影、剧集等类型互相归错类。
- 新视频和新采集影片按片名生成无声调拼音别名；词库随安装包提供，不依赖系统 ICU 中文转写数据，同名别名自动加数字后缀。
- 视频编辑支持修改别名；修复旧自动别名或修改别名后保留兼容引用，旧的别名详情和播放地址仍可解析，已删除或未发布影片不因旧别名重新公开。

## 新增

- 豆瓣资料补全增加按视频目录（包含全部子目录）、最近一天（24小时）和最近一周（7天）更新时间筛选；电影、电视剧、综艺和动漫使用同一条目获取链路。
- 显示当前范围的有编号、缺资料及无豆瓣编号数量；无编号影片明确跳过，不按片名猜测匹配。
- 每个目录、时间及处理模式分别保存续跑进度，并按管理员账号隔离；固定批次开始时间和影片ID上限，暂停／继续不改变范围，重置后可处理新入库内容。
- 暂停时等待当前请求结束，防止重启后的旧定时器重复执行；请求中不能切换或重置范围。
- 批量维护增加每批25部的拼音别名修复，可暂停续跑，不限于前5000部；默认只修复旧程序自动生成的别名，保留自定义别名。

## 删除

- 取消“未绑定就使用第一个视频分类”的隐式回退。不删除既有视频、分集或业务数据。

## 升级说明

升级前请备份数据库、`.env` 和上传文件。本次不新增数据库迁移。完整安装下载 `feifeicms8.5.zip`；已有站点可使用后台在线更新或 `feifeicms-update.zip`。从仓库源码更新时须执行 `composer install --no-dev --classmap-authoritative`，以安装拼音词库；ZIP 已包含运行依赖。

升级后先检查采集分类的已保存绑定。旧页面曾把未保存的建议显示成“已绑定”，这些分类需重新选择并保存；已误入其他目录的同来源影片可重新采集修正，已锁定影片请人工核对。拼音别名可在“工具 → 批量维护”修复，默认不改自定义别名。

豆瓣补全的“最近一天／一周”按视频更新时间计算，不是上映日期。新进度与旧版全站游标隔离，首次运行将按所选范围重新扫描；已存在的资料在“仅补齐缺失字段”模式不会被覆盖。遇到豆瓣验证或限流时请按提示处理 Cookie 或稍后重试，程序不绕过验证。

从旧主题布局升级时，请同时使用仓库提供的 Nginx／宝塔伪静态规则，网站运行目录保持 `public/`，不要公开 `view/`。安装包只包含默认 MXOne 前台模板、生产依赖及必要说明，不含站点配置、业务数据、采集源或其他前台模板。
