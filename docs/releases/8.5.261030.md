# FeiFeiCMS 8.5.261030

新增程序使用量与版本统计。程序维护者可以知道有多少安装实例近期仍在运行、分别使用什么版本；站点后台和前台不增加统计菜单、页面或脚本。

## 程序变化

- 首次运行后生成随机 UUID v4，以匿名安装 ID 去重。数据库中保留 ID，更新或清理缓存不会重新计数。
- 默认向 `https://tj.shankan.cc/v1/heartbeat` 发送程序版本、触发来源和 PHP 主次版本；不发送域名、站名、网址、账号、密码、内容或访客行为。
- 成功后 24 小时内不重复上报；失败退避重试。连接 / 总请求限制为 0.8 / 1.5 秒，不影响网站正常返回。PHP-FPM 在响应后执行，其他 SAPI 的收尾阶段可能最多增加 1.5 秒。公网超时调整见后续 `8.5.261030.1`。
- 本站 `.env` 可用 `USAGE_REPORTING=false` 完全关闭，或用 `USAGE_ENVIRONMENT=false` 关闭 PHP 版本信息。程序不会改写已有 `.env`。
- 新增 `php think feifei:usage:report`，供已有服务器调度按需调用。网页与命令行共用去重、限频与失败退避状态。

## 独立统计接收端

新增 Docker / PHP / SQLite 接收服务与管理面板，显示累计使用实例、近 7 / 30 天活跃、近 7 天新增、每日活跃趋势和版本分布，仅管理者登录后可见。不提供站点清单；不接收域名字段，不保存来源 IP 或请求日志，限流仅使用短期 HMAC 桶。

累计实例与独立人数不同。首次收到心跳只代表首次观测，旧版本、离线或关闭上报的站点无法纳入；公开程序也无法完全防止伪造安装 ID。详见 [程序使用统计](../程序使用统计.md)。

## 安装包与更新包

- `feifeicms8.5.zip`：完整干净安装包，已带生产依赖、默认模板和统计说明，只用于新安装。
- `feifeicms-patch-from-8.5.261029.zip`、`feifeicms-patch-from-8.5.261024.zip`、`feifeicms-patch-from-8.5.261023.2.zip`：分别针对所标版本的严格差量包，只含实际变化的程序文件及版本标识。
- `feifeicms-update.zip`：同时兼容上述三个基线的在线更新包；除实际变化外，允许保留旧更新器要求的必要核心文件。

所有 CMS 更新包均不包含模板、CSS/JS、图片字体、上传文件、`.env`、伪静态规则或网站配置；`config/version.php` 只作为程序版本标识。更新前备份数据库和网站文件，选择与当前版本对应的包。其他版本在暂存校验阶段拒绝覆盖；更早版本先升级到 `8.5.261023.2`。本次不改变业务表结构。

上一版的 Redis 设置修复和默认 MXOne 轮播样式修复继续保留；轮播样式仅进入完整包。
