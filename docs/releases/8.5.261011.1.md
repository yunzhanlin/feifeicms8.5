# FeiFeiCMS 8.5.261011.1

发布日期：2026-10-11。

## 修复

- 数据库恢复、安装和结构升级前检查触发器及建表读写权限；二进制日志限制导致的 1419 错误在操作开始前提示，不再恢复到一半才发现权限不足。
- 豆瓣资料缺少 IMDb 时，从该条目官方 App 详情页补充；来源未提供时保留表单原值并提示核对。
- 解析和远程弹幕不再将无效或失败状态当成成功；远程响应读取完成或失败后关闭资源。
- 远程弹幕兼容 `danmaku` 和 `danmuku` 字段，跳过无效条目，拒绝格式错误的 Token。
- Docker 配置只读持久挂载，初始化使用数据库与管理员命令，避免容器配置丢失及网页安装写入只读目录的问题。
- 安装器及时释放幂等升级语句返回的结果，修复全新安装出现 MySQL 2014 错误的问题。

## 新增

- 提供包含运行依赖、默认 MXOne 模板和安装程序的 `feifeicms8.5.zip` 完整安装包；在线更新继续使用 `feifeicms-update.zip`。

## 删除

- 发布仓库移除开发测试、截图和验收脚本、旧 CI、旧版初始化 SQL 与重复结构文件。
- 移除仅用于开发的 Composer 依赖；保留安装、部署、升级、数据迁移、模板说明和授权文件。
- 安装包和在线更新包剔除运行依赖附带的测试、开发配置及开发说明，保留依赖代码与许可证。

## 升级说明

先备份数据库、配置和上传文件，再在“工具 → 版本升级”确认更新。新安装可解压完整安装包，将运行目录设为 `public/`，访问 `/install.php`。触发器权限检查失败时，请数据库管理员处理后重试；程序不会自行修改 MySQL 全局安全设置。
