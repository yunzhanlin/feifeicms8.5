# FeiFeiCMS 8.5.261018.1

发布日期：2026-10-18。

## 更新

- 采集响应在解压数据写入时执行 5MiB 上限，避免压缩响应在检查前耗尽内存；正常 gzip、deflate 和 JSON 采集继续支持。
- 每次采集重试使用独立大小预算，成功或失败后释放响应资源。
- 分集剧情标签同时校验剧情和对应视频的发布、删除状态，未发布或已撤回影片的剧情不再出现在公开功能示例及模板标签中。
- 旧静态副本在升级收尾或新版启动时移至非公开的 `runtime/retired-static/` 保留；旧版更新器已有的安装清理步骤也可触发隔离。
- 更新 Nginx、宝塔、Apache 及开发服务器规则，禁止直接读取旧 `/generated` 文件。

## 新增

- 历史静态副本隔离与重复执行保护，不删除原副本内容；遗留的只读后台生成模板不会阻止站点启动。

## 删除

- 移除 HTML 静态生成功能，包括管理页面、生成接口、菜单、缓存统计及相关运行配置。
- 保留 URL 伪静态、自定义 URL、动态网站地图、RSS 和原有受限下载规则。

## 升级说明

升级前备份数据库、配置和上传文件，并先应用新的 Web 服务器规则禁止访问 `/generated`，重载 PHP-FPM，避免旧规则和旧代码缓存继续提供历史副本。只读部署请由管理员先将 `public/generated/` 移至非公开位置；浏览器或 CDN 的历史副本需另行清除。

本次不新增数据库迁移。全新安装下载 `feifeicms8.5.zip`；已安装站点在“工具 → 版本升级”检查并确认更新。安装包仅含干净程序、生产依赖和默认 MXOne 模板，不包含站点配置、业务数据或其他前台模板。
