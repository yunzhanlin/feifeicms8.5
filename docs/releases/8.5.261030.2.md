# FeiFeiCMS 8.5.261030.2

后台“视频 → 豆瓣评论采集”支持短评预览、勾选入库和批量采集。评论保存豆瓣原用户名、原评论时间及头像，头像下载到本站，影片详情与完整评论页可直接显示。

## 使用与入库规则

1. 在“系统 → 全局配置 → 豆瓣 Cookie”填写可用 Cookie，并确认影片编辑页的豆瓣 ID 正确。
2. 打开“视频 → 豆瓣评论采集”，查找或填写本站影片 ID，每页预览 20 条，勾选后入库。预览有效期 15 分钟。
3. 同一个豆瓣 ID 只入库到本站影片 ID 最大的未归档影片。选择旧影片时，预览自动定位到最新一部；若预览后出现更新的影片，入库会停止并要求重新预览。
4. 批量模式逐片采集 20 条热门短评，自动排除同豆瓣 ID 的旧影片，支持暂停和续跑。默认请求间隔为 4 秒。

按来源评论 ID 去重；重复采集不会重复新增，并可补齐旧版匿名导入记录。保留审核、置顶、投票、归档状态和本地编辑的正文。原数据缺少作者或时间时跳过，不创建虚假站内会员。

默认采集热门短评。豆瓣“最新排序”需要接口权限；Cookie 不具备权限、需要安全验证或访问过于频繁时明确提示并停止，不会把失败当成无评论成功。程序不绕过安全验证。头像下载限制文件大小和图片格式，不向图片服务器发送 Cookie；暂时下载失败时保留来源地址，重复采集可重试。

## 安装与升级

- `feifeicms8.5.zip`：完整干净安装包，包含生产依赖和默认模板，仅用于新安装。
- `feifeicms-patch-from-8.5.261030.1.zip`：从上一正式版手动覆盖升级的严格差量包，只包含有变化的文件。
- `feifeicms-patch-from-8.5.261030.zip`、`feifeicms-patch-from-8.5.261029.zip`、`feifeicms-patch-from-8.5.261024.zip`、`feifeicms-patch-from-8.5.261023.2.zip`：对应旧版的严格差量包。
- `feifeicms-update.zip`：兼容上述五个版本的在线更新包，包含所需程序变化和旧更新器要求的少量必要核心文件。

本次增加 `ffx_comments.author_avatar_url`，数据库结构版本升至 **18**。升级前备份数据库与程序。在线更新自动执行迁移；手动覆盖后执行：

```bash
php think feifei:schema:upgrade
```

所有更新包排除模板、CSS/JS、图片字体、上传文件、`.env`、伪静态规则及网站配置，仅保留程序版本标识 `config/version.php`。新增后台内容由程序渲染，使用现有后台布局和样式，无需覆盖模板。更早版本先升级到 `8.5.261023.2`，再选择对应差量包。

程序压缩包均排除 `doc/`、`docs/`；完整包只保留根目录 `README.md`，详细文档通过 GitHub 在线链接阅读。发布附件不含统计接收端压缩包或其校验文件。
