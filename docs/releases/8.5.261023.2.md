# FeiFeiCMS 8.5.261023.2

发布日期：2026-10-23。

## 更新

- 模板与资源分离：`.tpl` 页面和私有 PHP 扩展保留在 `view/<主题名>/`，CSS、JS、图片、字体移至 `public/theme-assets/<主题名>/`。
- 主题资源改为真实静态文件，不需要新增 `/theme-assets/` 专用伪静态，解决旧面板规则下后台样式、脚本及 Logo 返回 404 的问题。已经添加过专用规则的站点仍可兼容使用。
- 后台模板管理继续提供主题下的“assets”入口，显示真实文件路径，支持编辑前台 CSS、JS。
- 同步安装说明、模板制作教程和打包检查；完整安装包仍只包含默认 MXOne 前台模板及必要系统资源。

## 新增

- 兼容旧在线更新器的资源迁移。新版首次启动自动搬迁旧 `view/<主题名>/assets/` 中的静态文件，原目录及被替换的公开文件备份到 `runtime/retired-theme-assets/`。
- 资源迁移包含文件校验、并发锁和软链接检查；PHP、模板源码、隐藏文件等不会搬到公开目录。

## 删除

- 移除默认模板目录内的静态资源副本，不删除模板、PHP 扩展或业务数据。升级中的旧副本会先保留备份。

## 升级说明

升级前备份数据库、`.env` 和上传文件。本次无需数据库结构迁移；从 `8.5.261023.1` 及更早版本可通过后台检查更新安装。

全新安装下载 `feifeicms8.5.zip`，已有站点使用后台在线更新。旧目录搬迁需要本站 PHP 用户可写 `view/`、`public/theme-assets/` 和 `runtime/`。本次不需要调整站点页面的伪静态，也不要公开 `view/`。

制作或复制新主题时，请同时复制 `view/<主题名>/` 与 `public/theme-assets/<主题名>/`。资源仍使用 `ff_theme_asset()` 调用，无需修改模板标签。
