# FeiFeiCMS 8.5.261005.1 正式版修订 1

发布日期：2026-10-05。由 [8.5.261005](8.5.261005.md) 升级。

## 新增

- 增加历史采集资料补全命令，从已保存的来源快照补齐缺失的主演、导演、关键词、影片类型和上映资料。
- 默认只预览；确认执行时先备份原值，只补空值，不覆盖已有资料、锁定影片及播放线路。

## 更新与修复

- 修复采集更新时旧的空字段覆盖新资料，造成主演、导演等资料未保存的问题。
- 兼容 MacCMS 的 `vod_tag` 关键词和飞飞的 `vod_filmtime` 上映时间戳；无效日期不再阻断有效字段的读取。
- 上映资料仅提供年份或文字时保留原文，不生成不存在的月日。
- 修复前台空关键词阻断后备字段的问题；无独立关键词时可展示影片类型。
- 视频编辑显示已采集的关键词，公共视频 JSON 接口输出主演、导演、关键词和上映资料，便于其他站点继续采集。
- 补充模板字段说明，默认 MXOne 详情页使用 `vod_pubdate` 显示上映资料。

## 删除与兼容变化

- 不删除功能、数据或数据库表，不更改影片状态、播放线路、分集编号及历史更新时间。
- 继续支持 PHP 8.2～8.5、MySQL 5.7.13+ 和 8.x；更新包只包含程序及默认模板，不捆绑额外模板、站点配置或数据。
- 采集源没有提供的资料仍显示“暂无”，不自动编造主演、导演或日期。

## 升级说明

1. 备份数据库、`.env`、上传文件和自定义模板，在“工具 → 版本升级”确认更新，或手动覆盖程序并执行 `php think feifei:schema:upgrade`。
2. 已采集的数据可先在项目目录预览，再确认补全：

   ```bash
   php think feifei:collection:repair-metadata
   php think feifei:collection:repair-metadata --apply
   ```

3. 原值备份保存在 `runtime/metadata-backups/`，请妥善保存；重复运行不会再次修改已补齐的字段。
4. 没有来源快照的旧数据需要重新采集；如已生成静态页面，修复后重新生成。
