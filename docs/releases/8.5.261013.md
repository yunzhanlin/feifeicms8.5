# FeiFeiCMS 8.5.261013

发布日期：2026-10-13。

## 更新

- 安装和数据库结构升级不再依赖触发器权限或全局 `SUPER`，二进制日志开启时普通站点账号也可安装。
- 搜索变更由程序在影片写入事务中记录；兼容已有搜索触发器，保留事务回滚、增量同步和批量变更全量同步能力。
- 无触发器的新站备份可由普通站点账号恢复；含历史触发器的备份仍在恢复前检查权限，避免半途失败。
- 修复删除安装入口后旧 OPcache 条目使页面持续返回 503 的问题。
- 完善默认 MXOne 模板制作教程及原生 8.5 标签、参数、返回字段和调用示例。

## 新增

- 安装成功后自动删除 `public/install.php`，保留安装锁；删除失败提示手动处理，不回滚已安装数据。
- 完整安装包提供精简安装说明。

## 删除

- 完整安装 ZIP 中的 Docker 示例、可选服务配置样例、历史发布文档和独立 4.3 迁移插件。这些可选资料仍保留在 GitHub 仓库中。
- 在线升级 ZIP 不再包含仅供新装使用的 `public/install.php`。

## 安装与升级

全新安装下载 `feifeicms8.5.zip`；已安装站点在“工具 → 版本升级”使用 `feifeicms-update.zip` 更新。两种包均附 SHA-256 校验文件，只提供默认 MXOne，不包含实际站点配置、上传文件、采集源、播放器或业务数据。

升级前备份数据库、`.env` 和上传文件。默认 MXOne 随程序更新，已有修改请先备份或复制为独立模板。其他名称的自定义模板和站点数据不在更新包中。

启用 Meilisearch 时建议每分钟运行 `php think feifei:search:work`。
