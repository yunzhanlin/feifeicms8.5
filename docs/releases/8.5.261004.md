# FeiFeiCMS 8.5.261004 正式版

发布日期：2026-10-04。由 [Beta2.3](8.5.261004-beta2.3.md) 升级，版本标识遵循飞飞 4.3 的 `主版本.次版本.年月日` 格式。

## 新增

- 后台数据库备份记录并恢复 `ffx_*` 触发器；恢复旧版未包含触发器的备份时自动补齐搜索 outbox 触发器。
- 对 InnoDB 业务表使用同一事务快照导出，避免在线写入期间的跨表时间点不一致。
- 针对备份触发器语句、空播放数据与正式版标识增加回归检查。

## 更新与修复

- 订单确认在事务内锁定订单并复核发放标记，避免并发重复发放积分或 VIP。
- 采集更新保留既有播放线路与分集 ID；空地址或被过滤的线路不会删除已采集内容及其关联附件、评论和观看历史。
- 运行中的采集任务不能重新排队；仅允许已结束任务以原子状态转换方式重试。
- 后台数据库恢复不再以固定 128 MiB 上限拒绝本系统生成的大备份。
- 全量搜索同步以数据库时间水位确认旧 outbox 记录，不再一次载入整张队列表。
- 程序更新排队与执行共用互斥锁，并使用唯一临时状态文件，避免并发请求覆盖任务。

## 删除与兼容变化

- 未删除业务功能或数据表。非 InnoDB 表无法保证一致性，后台现在拒绝将其纳入一致性备份。
- 旧站 4.3 单文件数据升级插件继续作为独立附件发布；插件版本维持 v1.0.1。

## 部署与验证

- 升级前仍需备份数据库、站点配置和上传文件；数据库 DDL 无法事务回滚。
- GitHub CI 检查 PHP 8.2～8.5、Composer 依赖和 MySQL 集成测试。实际站点升级前应在隔离环境恢复一份备份并验证搜索、采集、订单与前台播放。
