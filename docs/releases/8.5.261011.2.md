# FeiFeiCMS 8.5.261011.2

发布日期：2026-10-11。

## 更新

- 修复缓存恰好过期或被清除时付费设置失效的问题；无效配置不再按免费模式放行。
- 管理员修改密码、用户名、角色或账号状态后撤销旧会话；同时修复登录与密码重置并发时旧密码回写的问题。
- 受限视频的下载附件在服务端执行点播权限检查，匿名用户不再获得受限下载地址；公开预告和字幕不受影响。
- 采集按分集标题、地址等身份匹配已有分集，不再使用响应顺序覆盖既有记录；增量、乱序和特别篇响应保留原分集及其关联数据。
- 再次采集保留管理员停用的线路与分集，不再自动恢复启用。
- 密码哈希覆盖完整密码，支持最多 200 字节，避免 bcrypt 静默忽略长密码尾部；兼容旧 MD5 和短 bcrypt 密码。
- 管理员用户名创建、安装和登录统一支持最多 80 个字符，登录时不再截断。
- 分类批量修改、排序、隐藏及归档后立即失效相关前台和 API 缓存。
- 发布包使用生产依赖与优化自动加载，重复执行打包流程不覆盖已经上传的发布文件。
- 发布包仅带默认 MXOne 模板与必需初始化数据，不含站点配置、采集源、播放器或业务数据。示例配置默认使用文件缓存与 MySQL 搜索，第三方接口留空；Docker 的 Redis 和搜索服务改为用户主动启用。

## 新增

- 在线更新维护保护：等待已有请求结束，安装期间返回 503，完成后刷新各 PHP-FPM 进程的程序缓存。
- 更新失败后的 `php think feifei:update:resume` 恢复命令。数据库迁移或回滚失败时继续保持维护，确认修复后才能恢复访问。
- 数据库迁移 017，为管理员增加会话撤销版本字段。

## 删除

- 无。

## 升级说明

1. 备份数据库、`.env` 和上传文件，在“工具 → 版本升级”确认更新。在线更新不会覆盖站点配置、上传文件和自定义前台模板。
2. 手动升级时先暂停站点写入，覆盖程序文件后执行 `php think feifei:schema:upgrade`，确认迁移 017 完成，并重载本站 PHP-FPM。
3. 升级后请重新登录后台和会员账号。旧 bcrypt 密码超过 72 字节的账号需要重置密码；旧格式无法确认被截断的尾部。
4. 首次从旧版升级到本修订版，请在更新完成后重载本站 PHP-FPM，确保新的维护入口生效。后续在线更新会自动使用维护保护。
5. 若更新因迁移失败保持维护，请先查看 `runtime/updates/` 的任务及备份，修复文件或数据库权限、执行结构升级，确认完整后再运行 `php think feifei:update:resume`。不要直接删除维护标记。

完整安装使用 `feifeicms8.5.zip`；在线更新使用 `feifeicms-update.zip`。两种发布包均附带 SHA-256 校验文件。
