# FeiFeiCMS 8.5.261023.1

发布日期：2026-10-23。

## 更新

- 修复资源库“删除”只停用、仍显示在正常列表的问题。删除改为移入回收站，不删除已有影片、播放线路、分集或采集历史。
- 删除资源库时取消待执行采集任务并停用关联计划任务；正在采集的资源库须等待任务结束后再删除。
- 采集领取、计划排队、手动排队和重试与资源库删除统一加锁，避免删除后仍有新任务进入队列。
- 资源库列表的长地址自动换行，固定操作列宽度，避免“修改／删除”被长地址挤出可视区域。

## 新增

- 视频和剧情资源库回收站，以及恢复入口。恢复后默认停用，保留原分类绑定；不会自动重启旧采集任务或计划任务。
- 添加重复地址时提示先检查正常列表或回收站，避免重复创建。
- 豆瓣补全页面说明上游未收录字段的处理方式：保留已有资料，不补造内容，扫描完成不等于缺失字段计数归零。

## 删除

- 无功能删除，不清理既有业务数据。

## 升级说明

升级前请备份数据库、`.env` 和上传文件。本次无需数据库迁移。完整安装使用 `feifeicms8.5.zip`，已有站点可通过后台版本升级安装更新。

删除后的资源库在“采集 → 视频资源库／剧情资源库 → 资源库回收站”恢复。恢复后请先核对分类绑定和启用状态，计划任务需要单独重新启用。
