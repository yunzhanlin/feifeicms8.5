# FeiFeiCMS 8.5.261013.1

发布日期：2026-10-13。

## 更新

- 修复面板禁用 `proc_open` 时在线更新无法启动的问题。程序优先使用 CLI，不可用时自动在 PHP-FPM 结束响应后执行，无需开启进程执行函数。
- PHP-FPM 更新在响应、会话保存和当前请求锁释放后开始，避免等待自身请求而无法进入维护。
- 两种更新方式共用任务互斥、SHA-256 校验、程序与数据库备份、维护闸门和失败恢复流程。

## 新增

- PHP-FPM 后台执行方式；可处理的 PHP 异常或能执行退出回调的错误会记录失败状态，并保留维护保护。服务器强制终止进程时，仍须检查备份和维护状态后手动恢复。
- 安装说明补充 PHP-FPM 执行时限与大站点计划任务建议。程序不自动修改面板的全局安全配置。

## 删除

- 无。

## 升级说明

全新安装下载 `feifeicms8.5.zip`，已安装站点在“工具 → 版本升级”确认更新。两个 ZIP 均只包含干净程序和默认 MXOne，附 SHA-256 校验文件，不包含实际配置和业务数据。

若旧版已因 `proc_open` 无法启动，旧版不能自行下载本修复。首次需要手动覆盖本修订版程序，或仅部署 `app/controller/admin/Updater.php`、`app/service/ProgramUpdater.php`、`public/index.php` 三个启动修复文件后，再从后台确认完整升级。部署前备份，部署后重载本站 PHP-FPM；不要关闭 `open_basedir` 或开启禁用的进程函数。

PHP-FPM 须支持 `fastcgi_finish_request`、`ignore_user_abort` 和 `set_time_limit`，并允许更新期间占用一个工作进程。如果服务器限制已结束响应的任务时长，请按数据库规模设置合适时限，或由服务器计划任务执行已确认的 `php think feifei:update:apply 任务ID`。不支持 CLI 或 PHP-FPM 后台执行的环境请手动升级。
