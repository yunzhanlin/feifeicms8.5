# FeiFeiCMS 8.5.261029

发布日期：2026-10-29。

## Redis 缓存修复

- 修复“系统 → 缓存设置”选择 Redis 后，运行时仍只读取 `.env` 的文件缓存驱动的问题。后台保存的驱动、缓存前缀和默认缓存时长在程序启动时生效，覆盖环境默认值。
- Redis 连接地址、端口、密码和数据库继续使用原有 `.env`，安装时留下的空地址按本机 `127.0.0.1` 处理。支持程序自带的 Predis 客户端。
- 保存缓存设置前校验实际写入和读回，连接失败或前缀无效时保留原设置。切换驱动时清除请求内缓存，并使原驱动及目标驱动中的站点设置缓存失效。
- 缓存前缀限定为字母、数字、冒号、下划线、连字符，避免文件缓存目录越界；不同网站应使用不同前缀。清理 Redis 仅操作本站前缀。

## 完整安装包

- `feifeicms8.5.zip` 用于全新安装，包含生产依赖、默认 MXOne 和系统模板、安装说明及必要伪静态规则。
- 包含首页轮播图片被压成横条的默认样式修复，以及本版缓存修复。只配置一条启用的轮播时仍只显示一条，需要多条内容才会切换。
- 不包含真实站点配置、管理员账号、密钥、上传内容、缓存、测试数据或私有模板。Meilisearch 部署脚本与详细部署文档保留在 GitHub 仓库中。

在线兼容包会在旧更新器校验暂存文件时检查当前版本，不匹配即停止，尚未覆盖程序。严格差量包仅对应文件名指定的单个基线。更早版本请先使用历史发布页中的 `8.5.261023.2` 更新包。

## 更新后检查

1. 更新前备份程序、数据库、`.env` 和上传内容；更新后刷新 PHP 程序缓存。
2. 到“系统 → 缓存设置”核对已有驱动和前缀；配置 Redis 的站点到“工具 → 缓存管理”确认“驱动：redis”和“正常”。模板编译缓存仍是文件，属于正常行为。
3. 检查首页、后台登录和缓存清理。Redis 不可用时可在后台改回文件缓存；保存时会校验目标驱动的读写。

本版没有数据库迁移。Meilisearch 是独立可选服务，更新不会自动安装或启动它，也不会修改已有搜索配置；启用方式见 [Meilisearch 部署与启用](../Meilisearch部署与启用.md)。
