# FeiFeiCMS 8.5.261004 Beta2.3

发布日期：2026-10-04。本版修复 [Beta2.2](8.5.261004-beta2.2.md) 的 4.3 数据升级遗漏与重复执行问题；旧站插件仍为 v1.0.1，**8.5 目标程序必须先更新到 Beta2.3 或更新版**。

## 新增

- 4.3 `vod_scenario` JSON 中的分集剧情现按集数写入独立 `ffx_scenarios` 表，与迁移后的视频关联。已在旧版迁移过的视频也可重跑补齐。

## 更新与修复

- 修复旧版 JSON 零起始剧情数组的集数错位、覆盖首集问题。
- 旧视频的“大陆/内地/香港/台湾”和“汉语/普通话/汉语普通话”在迁移时按现有采集规则标准化；重复迁移也能补正先前导入的旧值。
- 修复收藏表使用联合主键、重复迁移时错误引用不存在的 `id` 字段的问题。
- 用隔离版 4.3 预填充多线路剧集、分集剧情、电影、文章、人物、专题、标签、会员、评论、采集源、订单、充值卡、收藏、观看和评分数据；完成首次迁移、失败批次续跑及重复迁移，按旧 ID 对照完成 12 组关联检查，并通过前台搜索、详情、播放和剧情页面检查。

## 删除与兼容变化

- 未删除业务功能或数据表。Beta2.2 标签和附件保留供追溯，但不再建议作为 4.3 数据迁移的目标程序。
- 旧站插件仍只迁移数据库业务数据，不复制上传文件、模板、密钥或服务器配置；正式站迁移前请备份两边数据库并暂停旧站写入。

## 验证范围

- 本次验收使用隔离的原版 4.3（PHP 5.6）与独立 8.5（PHP 8.5）、MySQL 8.0 测试库；未在真实宝塔站点、MySQL 5.7 或任意真实旧站完整数据集上验证。
