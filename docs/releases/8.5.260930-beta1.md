# FeiFeiCMS 8.5.260930 Beta1

发布日期：2026-09-29。首个 8.5 测试版；以下内容以该版本标签中的程序为准。

## 新增

- 以 ThinkPHP 8 为内核的 PHP 8.2～8.5、MySQL 8 程序，使用 `ffx_*` 数据表；提供浏览器安装向导和增量数据库升级命令。
- Redis 缓存与会话、Meilisearch 全文搜索及 MySQL 搜索回退。
- 视频、分类、资讯、人物、专题、标签、用户、评论、播放线路与分集剧情等前后台基础功能。
- FeiFeiCMS 风格的后台界面、模板标签和 MXOne 前台示例模板；`/features` 展示模板调用方法。
- FeiFeiCMS、MacCMS JSON 视频采集及跨来源合并；公开播放地址的线路与分集编号从 1 开始。
- Docker 与宝塔部署示例、URL 伪静态及旧地址兼容。

## 更新与优化

- 相比 4.3，数据库改为规范化表结构，并将播放线路、分集、人物关联等数据独立保存。
- 后台底部版本号统一引用 `config/version.php`，避免各页面出现不同版本。

## 删除与兼容变化

- 本版是 8.5 系列首次发布，没有上一版 8.5 功能可删除。
- 原 ThinkPHP 2.1 程序保存在 `legacy/` 供对照，不在 PHP 8 运行时执行；旧数据库不能直接覆盖新表。

安装要求与操作说明见仓库根目录的 [README](../../README.md)。
