# FeiFeiCMS 8.5.261004 Beta2.2

发布日期：2026-10-04。此版是 [8.5.261003 Beta2.1](8.5.261003-beta2.1.md) 的旧站升级插件兼容修订版，保留旧标签和附件以便追溯。

## 新增

- 发布旧站单文件升级插件 v1.0.1：`feifeicms43-upgrade-v1.0.1.php`，以及对应的 SHA-256 校验文件。将插件重命名为 `ff43-upgrade.php` 后放在 4.3 网站根目录使用。

## 更新与优化

- 插件兼容原版 4.3 常用的 PHP 5.6：移除 PHP 7 类型声明、空合并运算符和 `Throwable` 捕获；改用 PHP 5.6 可用的安全令牌生成方式及字符串形式的子进程命令。
- 继续对命令及参数逐个转义，旧库密码仍仅通过子进程环境变量传递，不进入 URL 或命令行参数。
- 独立旧站与新站完成浏览器迁移流程验证：预检、分批迁移、完成后搜索同步、重复执行不新增相同记录；PHP 5.6、7.4、8.5 语法检查通过。

## 删除与兼容变化

- 未删除业务功能或数据表。旧版 v1.0.0 插件附件仍保留在 Beta2.1 发布页；PHP 5.6 旧站应使用本版 v1.0.1，勿混用。
- 插件不原地替换 4.3 程序，也不迁移模板、上传附件或服务器配置；迁移前必须备份两边数据库并暂停旧站写入，验收后删除旧站根目录的升级入口。

## 验证范围

- 本次在独立测试环境运行了原版 4.3（PHP 5.6）与新安装的 8.5（PHP 8.5），验证了样例业务数据迁移与前台搜索；未声称已覆盖所有真实旧站数据、全部采集源类型或宝塔面板内的站点部署。

## 后续发现的已知问题

- 加入多集剧情、收藏记录等预填充数据后发现：本版目标程序未迁移旧版 `vod_scenario`；再次迁移已有收藏时还可能报错。请使用 [Beta2.3](8.5.261004-beta2.3.md) 作为 8.5 目标程序。已用本版迁移的测试站升级目标程序后，可重新运行迁移以补齐剧情。
