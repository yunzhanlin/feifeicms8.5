# FeiFeiCMS 8.5.261030.1

修复统计接收服务经过公网代理时，响应稍慢就被误判失败的问题。实测 Cloudflare 路径的正常响应可能接近 3 秒，原有 1.5 秒总时限不足；本版将连接 / 总请求时限调整为 1.5 / 4 秒，继续保留每日限频、失败退避和异常隔离。PHP-FPM 在页面响应完成后上报，其他 SAPI 的请求收尾阶段可能最多增加 4 秒。

匿名统计只发送随机安装 ID、程序版本、触发来源和可选的 PHP 主次版本，不发送域名、站名、账号、内容或访客信息。可在本站 `.env` 设置 `USAGE_REPORTING=false` 关闭；站点后台和前台不增加统计页面或脚本。接收端由维护者部署，站长无需安装。详见 [安装说明中的统计设置](../安装说明.md#匿名程序使用统计)。

## 安装与更新

- `feifeicms8.5.zip`：完整干净安装包，包含生产依赖与默认模板，仅用于新安装。
- `feifeicms-patch-from-8.5.261030.zip`：从 `8.5.261030` 手动覆盖升级的严格差量包。
- `feifeicms-patch-from-8.5.261029.zip`、`feifeicms-patch-from-8.5.261024.zip`、`feifeicms-patch-from-8.5.261023.2.zip`：对应旧版的严格差量包。
- `feifeicms-update.zip`：兼容上述四个版本的在线更新包，包含所需程序变化和旧更新器要求的少量必要核心文件。

所有更新包都排除模板、CSS/JS、图片字体、上传文件、`.env`、伪静态规则和网站配置；`config/version.php` 仅作为程序版本标识保留。更新前备份，选择与当前版本对应的包。其他版本在暂存校验阶段拒绝覆盖；更早版本先升级到 `8.5.261023.2`。本次不改变业务表结构。

发布附件只提供 CMS 安装包、更新包及迁移插件，不包含统计接收端压缩包或其校验文件。

程序压缩包排除 `doc/` 和 `docs/` 目录；根目录保留 `README.md`，其中的详细文档链接指向 GitHub 在线说明。
