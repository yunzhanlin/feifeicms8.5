# FeiFeiCMS 8.5.261003 Beta2

发布日期：2026-10-03。相对于 [8.5.260930 Beta1](8.5.260930-beta1.md)。

## 新增

- 独立的分集剧情采集资源库；可关联视频资源库，并按远程视频 ID 匹配本地影片。
- 分集剧情按“影片 → 全部剧集”集中管理，支持同页编辑、保存和关联查看。
- FeiFeiCMS 4.3 数据升级插件，提供旧库预检、分批迁移、旧 ID 对照和中断重跑；旧库保持只读。
- 超级管理员登录后的 GitHub Release 版本检测与确认更新；更新包自动生成、SHA-256 校验、程序与数据库备份、后台安装和状态反馈。
- MySQL 触发器驱动的搜索增量队列与处理命令 `feifei:search:work`；新增管理员角色权限控制。

## 更新与优化

- 首页栏目、分类、导航、友情链接、轮播和广告等公共数据纳入缓存，减少重复的分类名称补查；新增相关数据库索引与后台修改后的失效处理。
- Meilisearch 全量重建改为临时索引构建并交换；修复持久化空搜索地址覆盖 `.env` 的问题，并在增量任务失败时保留待同步记录。
- 视频合并保留不同采集来源的播放线路、分集和剧情，避免同名线路相互覆盖。
- 采集源表单增加剧情源配置，前台搜索、缓存管理和后台管理员操作做了可靠性修复。
- 自动更新仅在新 Release 的安装包与校验文件都已上传后提示；数据库备份包含触发器。

## 删除与兼容变化

- 公开采集 API 默认不再输出播放地址；管理员明确开启后也仅输出免费影片的地址。依赖旧版默认明文地址的客户端需要调整配置。
- 分集剧情后台由逐集平铺列表改为按影片聚合管理；剧情数据和原有独立表未删除。
- 本版没有删除数据库表，也没有移除 MXOne 示例模板或旧地址兼容功能。

## 升级注意

- 从 Beta1 升级需执行数据库迁移 013～015；手动升级命令见 [README](../../README.md)。
- 后台一键更新要求站点 PHP 用户对程序目录有写入权限；不授予该权限时应使用手动升级。
- GitHub 新提交不会直接触发站点更新；必须发布带有版本号、安装包和校验文件的 Release。
