# FeiFeiCMS 8.5.261004.1 正式版修订 1

发布日期：2026-10-04。由 [8.5.261004 正式版](8.5.261004.md) 升级。

## 新增

- 后台更新启动前实际运行并核对 PHP CLI 主次版本；支持面板将 PHP CLI 安装在站点 `open_basedir` 之外的部署方式。
- 版本检测支持正式版日期后的修订号，例如 `8.5.261004.1`。

## 更新与修复

- 修复宝塔及类似面板启用 `open_basedir` 后，`is_file(PHP_BINDIR . '/php')` 错误拒绝可用 CLI 的问题。
- 修复后台工作进程使用 `/dev/null` 作为 `proc_open` 描述符时，仍被 `open_basedir` 拒绝的问题。

## 删除与兼容变化

- 未删除业务功能或数据表；数据库结构不变。旧站 4.3 数据升级插件仍为 v1.0.1。
- 若面板禁用了 `proc_open`、站点账号不能执行同版本 PHP CLI，或程序目录不可写，后台仍会明确拒绝自动更新；可使用手动升级。

## 验证

- 增加受限 `open_basedir` 下的 CLI 探测和后台子进程启动回归测试。
- 在本地面板虚拟机使用站点 PHP 用户、PHP 8.5.10 和实际站点 `open_basedir` 配置验证 CLI 探测及子进程启动。
