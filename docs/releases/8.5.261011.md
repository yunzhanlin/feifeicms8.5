# FeiFeiCMS 8.5.261011

## 修复

- 视频编辑改为差量保存分集，保留分集 ID、时长、季关联、附件、评论、观看记录及停用状态；含 `$` 的播放地址不再截断。
- 修改片名等资料不再重写播放线路。文本中移除分集不会默认删除数据；明确勾选删除才执行，超过数量限制拒绝保存。
- 系统设置读取异常时停止放行付费内容，不缓存失败产生的空配置。
- 清理 Redis 仅处理本站前缀；局部缓存清理不再清空其他业务或其他站点的数据。
- VIP 到期、续费和充值卡使用明确的 UTC 时间计算，后台输入按站点时区转换。
- 增量或不完整剧情响应不再删除已有分集剧情；不同来源并发采集同一影片通过身份锁串行合并。
- 数据库恢复后失效本站缓存并标记搜索索引需要重建；完成全量同步前使用 MySQL 搜索，恢复与索引同步不能并发执行。
- 用户禁用、归档、密码重置后撤销旧会话；评论、收藏、观看记录、充值与弹幕写入检查当前用户状态。
- 设置审计日志的新旧值统一脱敏；新增历史日志脱敏命令，支持预览和重复执行。
- 4.3 分类迁移支持父分类后创建、跨批次关联和重复迁移，不再丢失逆序父子关系。
- 留言板与视频评论共用游客、禁言 IP、敏感词规则；收藏分页，评论回复批量限量加载。
- 登录跳转拒绝反斜线、控制字符和编码变体，避免站外跳转。

## 新增与完善

- 接入后台播放器解析配置，支持 JSON、iframe、无扩展名直链及强制解析；解析域名白名单与观看权限校验同时生效。
- 接入远程弹幕 API、Token、匹配、超时、缓存及数量限制；匹配地址只允许同源。
- 采集与 API 使用后台已启用的播放器标识，不再输出私有线路后缀；没有可用播放器的影片跳过入库。
- 豆瓣资料获取按作品响应识别类型，完善网页与接口回退，不根据本地电影／电视剧分类固定接口。
- 补充播放器、弹幕的模板调用说明。

## 升级说明

先备份数据库、配置和上传文件，再通过后台版本升级或覆盖文件升级。手动升级须执行 `php think feifei:schema:upgrade`。会员需要重新登录；Redis 共用时必须使用不同站点前缀。数据库恢复后执行 `php think feifei:search:sync` 重建索引。

可使用 `php think feifei:audit:redact` 预览历史日志脱敏，再加 `--apply` 执行。既有备份不自动修改，曾进入日志的密钥建议更换。

## 删除

- 删除远程弹幕的固定空响应和普通视频保存时的分集全删重建逻辑。没有删除现有后台功能或默认模板。
