# FeiFeiCMS 8.5.261019

发布日期：2026-10-19。

## 更新

- 播放器填写解析器 URL 后，所有地址和资源标识均交给该接口解析，包括带 `.m3u8`、`.mp4` 后缀的地址；留空则直接播放，不再由全局解析地址自动接管。
- 支持将非 HTTP 资源标识原样传给解析接口；直连播放仍要求 HTTP／HTTPS 地址，解析接口保留域名白名单、公网地址和返回结果校验。
- 播放器配置错误在播放器内提示，不再导致整个播放页返回 500。
- 修复播放地址重复 HTML 转义导致签名参数变化的问题，更新播放器脚本缓存版本。
- 兼容解析接口将 `type` 用作“单线程”等传输描述的情况，可从返回地址扩展名识别媒体类型；支持 HLS 和常见媒体 MIME 类型，明确的有效媒体类型仍保持优先。
- 后台视频列表、线路管理、评论及播放记录中的影片链接统一遵循 URL 配置；播放器下方的影片链接使用同一规则。
- 修复 URL 设置未保存时默认自定义规则不生效的问题，同时保持已保存规则、后缀、关闭开关及旧地址兼容。
- 前台 HTML 压缩开关接入实际响应处理，压缩普通排版空白，保留行内文字间隔及脚本、样式、预格式文本、代码块和表单文本。后台、JSON、静态资源和下载文件不参与处理。
- 修复资源分类绑定／解绑编辑框靠近页面边缘时被截断的问题，支持取消、Esc 和点击外部关闭，同一时间只展开一个编辑框，取消不改变既有绑定关系。
- 资源列表的全选、反选、采集选中按钮靠左，分页居中显示，并统一按钮、当前页高亮及不可用状态样式。

## 新增

- 新增和编辑空播放器配置时显示可直接使用的 JSON 示例；仅查看不会修改已保存配置。
- 资源库分页增加首页、尾页和附近页码入口，翻页保留分类、时间和搜索条件。

## 删除

- 无功能删除；播放器不再依赖 `force_parser` 决定是否调用解析接口。

## 升级说明

升级前请备份数据库、`.env` 和上传文件。本次不新增数据库迁移。

升级后请检查每个播放器的解析器 URL：需要解析的播放器单独填写接口并配置白名单；留空的播放器按直链处理，带扩展名时自动识别格式，无扩展名时默认 M3U8，可用 `direct_type` 改为 MP4。接口示例见[模板制作与标签调用指南](../模板标签.md#播放器与远程弹幕)。

全新安装下载 `feifeicms8.5.zip`，已安装站点在“工具 → 版本升级”确认更新。安装包仅含干净程序、生产依赖和默认 MXOne 模板，不包含站点配置、业务数据、采集源、第三方接口或其他前台模板。
