# FeiFeiCMS 8.5.261018

发布日期：2026-10-18。

## 更新

- 手动新增或编辑视频保存成功后返回视频列表，并显示添加／保存成功提示，避免跳回原编辑页却没有反馈。
- 视频保存校验失败时显示具体原因，保留已填写的资料、播放地址及删除确认选项，不再只显示通用错误页。
- 新建线路默认选择后台已启用的播放器；没有可用播放器时提示先配置，也可不填写播放地址，仅保存视频资料。未注册或已停用的播放器仍不能入库。
- 接通“附件设置 → 图片代理”的外部防盗链代理配置，按指定域名及其子域名处理视频封面、人物图片、专题封面、轮播和友情链接图片。
- 原图地址整体编码后传给代理，避免参数丢失；本地图片、其他域名及已处理地址不会重复套用代理。数据库和采集输出 API 保留原始图片地址。
- 修复默认 MXOne 部分图片地址被重复 HTML 转义、导致多参数代理地址失效的问题。
- 完善模板制作指南中的图片代理配置和调用示例。

## 新增

- 图片地址处理方法 `ff_url_img()`，供自定义模板处理原始图片地址；代理前缀支持使用 `{url}` 指定原图参数位置。

## 删除

- 移除未配置播放器时误导性的“默认线路”预选项，改为明确的播放器选择提示。
- 无功能删除。

## 升级说明

全新安装下载 `feifeicms8.5.zip`，已安装站点在“工具 → 版本升级”检查并确认更新。升级前请备份数据库、配置及上传文件；本次不新增数据库迁移。

安装包仅包含干净程序、生产依赖和默认 MXOne，不含站点配置、业务数据或其他前台模板。播放器和图片代理由站长自行配置；未启用图片代理时，图片地址保持原样。
