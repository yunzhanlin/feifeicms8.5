# FeiFeiCMS ThinkPHP 8 本地验收记录

验收地址：`http://feifeicms-modern.localhost:19101/`

## 核心结论

- 这是 FeiFeiCMS 4.3 功能、后台结构、模板标签和 URL 合同在 ThinkPHP 8 上的升级实现，不依赖 TP2 运行时。
- 45 张 `ffx_*` 规范化表完成安装，Doctor 清单全部通过；Redis 实际读写和 Meilisearch 连接通过。
- 宝塔 PHP 8.5 PHPUnit 69 项测试、623 条断言通过；Composer 严格校验通过，依赖安全审计无漏洞公告。
- 管理后台 48 个 GET 页面通过登录态巡检，无 SQL/Fatal/模板错误或桌面横向溢出；最终保留 33 张后台截图，浏览器控制台零错误。
- MXOne 最终保留 9 张桌面/手机截图，无失败资源、无控制台错误。

## 采集与播放

- 已添加资源库按原 FeiFeiCMS 操作方式使用：名称、接口地址、AppKey、启用状态；协议自动识别，不要求手写 JSON。
- 实际资源库读取结果：49 个上游分类、单页 20 条、共 450 页；已验证分类映射、预览、选中/分页/全部采集和断点任务。
- 实际影片“无可替代”已写入三集线路；ArtPlayer + hls.js 读到 HLS `readyState=4`、时长 45:49、媒体错误为空。
- 定时调度器每分钟运行，最近服务结果为 success。
- 计划任务可选每隔 N 分钟、每小时指定分钟或每天指定时间。
- 资源库列表的“采集当天/本周/全部”使用 POST 直接建任务并立即执行，不再跳到资源浏览页。
- 分类绑定把 `0` 持久化为明确的“不绑定”状态；页面刷新后仍显示不绑定，导入时使用本站默认分类。
- FeiFei JSON 与 MacCMS JSON 双来源合并回归保留两条外部引用、两组播放线路和独立剧情；关闭“采集后自动审核”时合并路径不会绕过设置发布草稿。
