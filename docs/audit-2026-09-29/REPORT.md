# FeiFeiCMS 后台功能对齐复验（2026-09-29）

## 结论

此前只读审查发现的后台外围模块缺口已经完成整改。当前版本以 FeiFeiCMS 4.3/7.4 的后台信息结构和操作方式为基线，在 ThinkPHP 8、PHP 8.5、MySQL 8.4、Redis 与 Meilisearch 上重新实现；不再把“页面能打开”当成功能完成。

本轮在本地宝塔 Nginx + PHP-FPM 实例 `http://feifeicms-modern.localhost:19101/` 完成：

- 48 个登录态后台 GET 页面逐页巡检，全部正常渲染，无 404、SQLSTATE、Fatal、模板错误或桌面横向溢出；
- 分类、视频、线路、分集、文章、专题、人物、用户、播放器、轮播、友链、导航、广告、标签、计划任务、卡密、附件、静态生成、缓存与数据库备份/恢复均经真实 CSRF 表单写入；
- 验收数据已清理，静态文件已重新生成，不保留测试影片、用户、卡密、附件或备份；
- PHP 8.5 PHPUnit 52 项、461 条断言通过；45 张业务表安装成功，数据库、Redis 与 Meilisearch 健康检查通过；
- FeiFei JSON 与 MacCMS JSON 双来源真实入库回归通过：同片合并为一条，保留 2 条外部来源、2 组播放线路、2 条独立分集剧情，地区和语言按约定标准化；
- “采集当天”通过 POST 直接创建并执行任务，不再跳转资源库；分类映射保存 `0` 后保持“不绑定”；
- 模板编辑器读取和保存原始 ThinkPHP/FeiFei 标签源码，不再二次 HTML 编码；
- 计划任务支持每隔 N 分钟、每小时和每天三种周期。
- 33 张最终后台截图逐张复核完成，桌面端无横向溢出、控制台零错误；移动端保留经典后台的密集表格，并提供横向查看而不改写信息结构。

## 模块结果

1. **系统与设置**：恢复 4.3/7.4 顶栏、左栏和系统信息表；全局、URL、付费、播放、内容、缓存/搜索、采集、附件、邮件、注册、评论、微信配置均有独立分区。站点开关、名称/SEO、列表数量、注册、评论、弹幕、支付访问控制、播放器、采集、附件、搜索等核心设置已接入运行时。
2. **工具**：缓存统计和分层清理；附件上传、远程下载、缩略图和删除；模板浏览、新建、编辑和删除；同名检测、受控数据替换、批量维护；首页/分类/视频/文章/专题静态镜像及 sitemap/RSS；计划任务和用户记录逐条删除/分类清空均有可执行链路。
3. **分类与导航**：层级、排序、状态、批量操作、前台导航输出和分类筛选已接通。
4. **采集**：资源库、协议自动识别、分类绑定、资源预览、当天/本周/全部、按 ID/关键词/勾选、任务与重试、来源标识、字段映射、合并和独立剧情采集可用。
5. **视频**：左侧 18 个旧版入口、视频列表与批量操作、豆瓣补全/查重/评论、来源标识、豆瓣/IMDb ID、演职人员、图片、扩展字段、经典台词、看点糟点、大结局和多线路分集编辑已对齐。
6. **分集剧情**：独立顶栏、独立 `ffx_scenarios` 表，按 `media_id + episode_no` 唯一关联视频；支持手工 CRUD、审核筛选和 FeiFei 剧情 JSON 同步。
7. **文章、人物、专题**：分别提供列表、筛选、批量发布/撤审/归档、扩展资料、图片、SEO、标签、人物作品和专题影片关联；前台详情与列表读取真实关联数据。
8. **评论与弹幕**：对象筛选、审核、置顶、回复、删除、批量操作、频率/IP/敏感词限制和前台提交链路已接通。
9. **标签**：视频聚合、文章话题、新增、重命名、合并、删除及前台关系表均可用。
10. **用户与运营**：用户 CRUD/封禁/积分/VIP、注册登录、收藏/记录/评分/顶踩、管理员与权限、订单、卡密批量生成/兑换、内容权益、广告/轮播/友链前台输出均已实现。
11. **数据库**：列表、备份、恢复、删除、优化、`CHECK TABLE` 检查及按存储引擎修复维护可用；危险操作要求明确确认并写审计日志。

## 边界

- 支付宝、微信支付、PayPal 等外部网关的配置项和站内订单状态链已保留，但真实签名与回调仍必须使用具体商户平台的账号、密钥和沙箱/生产回调地址验收；未提供凭据时不会伪造“支付成功”。
- 邮件设置已提供真实 SMTP SSL/TLS 登录和测试发送；实际送达仍需要有效邮箱、授权码及网络出口。微信公众号回调仍需要真实平台凭据与公网可达地址。
- 后台外观按 FeiFeiCMS 经典样式复刻，底层使用 ThinkPHP 8 的控制器、服务、规范化表、CSRF、权限与审计实现，不继续运行旧 TP2 代码。
