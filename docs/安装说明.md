# FeiFeiCMS 8.5 安装说明

## 环境要求

- PHP 8.2～8.5，启用 `curl`、`dom`、`fileinfo`、`gd`、`intl`、`mbstring`、`openssl`、`pdo_mysql`、`xml`、`xmlwriter`、`zip`。
- MySQL 5.7.13+ 或 MySQL 8.x；不支持 MySQL 5.6、5.5 和 MariaDB。
- Nginx 或 Apache。安装包已包含生产依赖，不需要另行安装 Composer。

## 安装步骤

1. 解压 `feifeicms8.5.zip` 到网站目录，保持原有目录结构。
2. 将网站运行目录设置为 `public/`，不能设置为程序根目录。让本站 PHP-FPM 用户能够写入 `runtime/`、`public/uploads/` 及程序根目录中的安装配置；不要把所有文件权限改为 `777`。
3. 为本站创建一个空 MySQL 数据库和独立账号，授予该数据库的建表、修改表结构和读写权限。不需要全局 `SUPER`、触发器权限或调整二进制日志。
4. Nginx／宝塔的伪静态使用 [deploy/baota/thinkphp.conf](../deploy/baota/thinkphp.conf)；将规则放在本站 `server` 中、`location` 之外。Apache 可参考 [deploy/apache/feifeicms.conf](../deploy/apache/feifeicms.conf)，并启用 `mod_rewrite`。
5. 访问 `https://您的域名/install.php`，填写数据库、管理员账号和站点信息。安装程序拒绝覆盖已有 `ffx_` 数据表。
6. 安装成功后自动生成 `.env` 和 `runtime/install.lock`，并删除 `public/install.php`。如果成功页提示无法删除，手动删除该文件；不要删除安装锁。
7. 访问 `https://您的域名/admin.php` 登录后台。管理员密码使用安装时自行设置的密码，没有通用默认密码。

上面的伪静态路径相对于程序根目录；不要将 `view/`、`config/`、`vendor/`、`runtime/` 暴露为公开目录，不能用软链接对外开放模板。

## 配置与模板

默认使用文件缓存和 MySQL 搜索，不需要 Redis 或 Meilisearch。播放器、采集源、SMTP、支付及第三方接口由管理员自行配置，安装包不包含预设账号、第三方密钥或业务数据。

采集前在“系统 → 播放来源”添加并启用对应播放器标识；未注册或停用的播放器线路不会入库。定时采集任务在后台“工具 → 计划任务”中配置，再按页面说明设置服务器调度。启用 Meilisearch 后，每分钟执行 `php think feifei:search:work`；第一次启用或直接通过其他工具修改影片数据后，执行 `php think feifei:search:sync`。

前台仅包含默认 MXOne。模板位于 `view/mxone/`，静态资源位于 `public/mxstatic/`；`view/admin/` 和 `view/install/` 为系统页面，不是额外的前台模板。完整调用方法见 [模板制作与标签调用指南](模板标签.md)；访问 `/features` 可查看功能示例。

## 在线更新

更新前备份数据库、`.env` 和上传文件。超级管理员在“工具 → 版本升级”检查新版本并确认更新。自动更新需要本站 PHP 用户能够写入程序目录、执行 `proc_open`，并使用同系列 PHP CLI。站点配置、上传数据及其他名称的自定义模板不进入更新包；默认 MXOne 会随程序更新，修改默认模板前请备份或复制为独立模板。

如果更新失败，不要删除维护标记。先查看 `runtime/updates/` 的日志及备份，修复文件或数据库问题并执行 `php think feifei:schema:upgrade`、`php think feifei:doctor`，确认正常后执行 `php think feifei:update:resume`。
