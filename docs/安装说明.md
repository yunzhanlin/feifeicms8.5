# FeiFeiCMS 8.5 安装说明

## 环境要求

- PHP 8.2～8.5，启用 `curl`、`dom`、`fileinfo`、`gd`、`intl`、`mbstring`、`openssl`、`pdo_mysql`、`xml`、`xmlwriter`、`zip`。
- MySQL 5.7.13+ 或 MySQL 8.x；不支持 MySQL 5.6、5.5 和 MariaDB。
- Nginx 或 Apache。安装包已包含生产依赖，不需要另行安装 Composer。

## 安装步骤

1. 解压 `feifeicms8.5.zip` 到网站目录，保持原有目录结构。
2. 将网站运行目录设置为 `public/`，不能设置为程序根目录。让本站 PHP-FPM 用户能够写入 `runtime/`、`public/uploads/` 及程序根目录中的安装配置；不要把所有文件权限改为 `777`。
3. 为本站创建一个空 MySQL 数据库和独立账号，授予该数据库的建表、修改表结构和读写权限。不需要全局 `SUPER`、触发器权限或调整二进制日志。
4. Nginx／宝塔的伪静态使用 [deploy/baota/thinkphp.conf](../deploy/baota/thinkphp.conf)；将规则放在本站 `server` 中、`location` 之外。Apache 可参考 [deploy/apache/feifeicms.conf](../deploy/apache/feifeicms.conf)，并启用 `mod_rewrite`。
5. 访问 `https://您的域名/install.php`，填写数据库、管理员账号和站点信息。安装程序拒绝覆盖已有 `ffx_` 数据表。
6. 安装成功后自动生成 `.env` 和 `runtime/install.lock`，并删除 `public/install.php`。如果成功页提示无法删除，手动删除该文件；不要删除安装锁。
7. 访问 `https://您的域名/admin.php` 登录后台。管理员密码使用安装时自行设置的密码，没有通用默认密码。

上面的伪静态路径相对于程序根目录；不要将 `view/`、`config/`、`vendor/`、`runtime/` 暴露为公开目录，不能用软链接对外开放模板。

## 配置与模板

默认使用文件缓存和 MySQL 搜索，不需要 Redis 或 Meilisearch。播放器、采集源、SMTP、支付及第三方接口由管理员自行配置，安装包不包含预设账号、第三方密钥或业务数据。

采集前在“系统 → 播放来源”添加并启用对应播放器标识；未注册或停用的播放器线路不会入库。定时采集任务在后台“工具 → 计划任务”中配置，再按页面说明设置服务器调度。启用 Meilisearch 后，每分钟执行 `php think feifei:search:work`；第一次启用或直接通过其他工具修改影片数据后，执行 `php think feifei:search:sync`。

需要启用 Meilisearch 时，请参照在线文档 [Meilisearch 部署与启用](https://github.com/yunzhanlin/feifeicms8.5/blob/main/docs/Meilisearch部署与启用.md)，完成服务启动、后台配置、首次同步和每分钟任务。文档提供宝塔／普通 Linux 和整站 Docker Compose 两种部署方式。

使用 Redis 时，先在 `.env` 配置 `REDIS_HOST`、`REDIS_PORT`、`REDIS_PASSWORD`、`REDIS_DB`，再到“系统 → 缓存设置”选择 Redis 并保存。空 Redis 地址按本机 `127.0.0.1` 处理。后台保存的驱动、缓存前缀和默认缓存时长会覆盖环境默认值，保存前校验真实读写；失败时保留原设置。缓存前缀只使用字母、数字、冒号、下划线和连字符，不同网站使用不同前缀。到“工具 → 缓存管理”核对驱动及状态；模板编译缓存仍保存为文件。

前台仅包含默认 MXOne。`view/mxone/` 存放 `.tpl` 页面和 `extensions/` PHP 展示扩展，CSS、JS、图片和字体放在 `public/theme-assets/mxone/`。后台、安装页和共享播放器分别使用同名的 `admin`、`install`、`shared` 目录，不是额外前台模板。完整调用方法见 [模板制作与标签调用指南](模板标签.md)；访问 `/features` 可查看功能示例。

`view/` 不能直接访问、下载或映射到公共目录。`public/theme-assets/` 是真实公开静态目录，不需要 `/theme-assets/` 专用 rewrite；页面 URL 仍使用安装步骤中的伪静态规则。静态目录不能放 PHP、模板源码、配置、密钥或软链接。模板编辑器仅允许编辑前台 `.tpl` 和 CSS、JS，不允许在线修改 PHP 扩展。复制主题时同时复制 `view/<主题名>/` 和 `public/theme-assets/<主题名>/`。

旧在线更新器可继续接收升级包。新版首次启动时会搬迁旧 `view/<主题名>/assets/` 中的允许资源，原目录及被替换的公开文件备份在 `runtime/retired-theme-assets/`。迁移需要本站 PHP 用户可写主题目录、`public/theme-assets/` 和 `runtime/`；手动覆盖升级也应保留这些权限。全新安装无需迁移。之前添加过的主题资源 rewrite 仍能兼容，不必修改或关闭源码访问保护。

## 匿名程序使用统计

安装后默认每天最多发送一次匿名程序心跳，用于汇总安装实例数、活跃数和版本分布。发送随机安装 ID、程序版本、触发来源及 PHP 主次版本，不发送域名、站名、账号、内容或访客信息；后台与前台均不增加统计页面或代码。接收端由程序维护者独立部署，站长无需部署。可在本站 `.env` 添加 `USAGE_REPORTING=false` 完全关闭，或用 `USAGE_ENVIRONMENT=false` 关闭 PHP 版本信息，详见 [程序使用统计](程序使用统计.md)。

## 在线更新

更新前备份数据库、`.env` 和上传文件。超级管理员在“工具 → 版本升级”检查新版本并确认更新。本站 PHP 用户须能够写入程序目录；程序优先使用同系列 PHP CLI，面板禁用 `proc_open` 时自动使用 PHP-FPM 后台执行，无需开启被禁用的进程函数。FPM 须允许结束响应和调整执行时限；若面板仍限制已结束响应的任务时长，大站点建议改用服务器计划任务或手动升级。

从 `8.5.261024` 起，更新包不包含任何模板、模板 CSS/JS、图片字体、上传文件、`.env`、伪静态规则或网站配置；`config/version.php` 仅作为程序版本标识保留。完整安装包包含默认 MXOne 和必要系统模板，只用于新安装，不要覆盖到已有网站。

`8.5.261030` 支持从 `8.5.261023.2`、`8.5.261024` 或 `8.5.261029` 直接在线更新。手动更新选择与当前版本对应的严格差量包 `feifeicms-patch-from-<当前版本>.zip`，备份后覆盖；后台在线更新使用 `feifeicms-update.zip`，它包含三条升级路径所需的程序变化和旧更新器要求的少量核心文件。暂存版本文件会在覆盖程序前检查版本，其他版本会被拒绝；更早版本先使用历史发布页中的 `8.5.261023.2` 更新包。本次没有数据库结构迁移，所有更新包保留现有模板、样式和网站配置。默认 MXOne 轮播样式修复仅进入完整安装包。

如果更新失败，不要删除维护标记。先查看 `runtime/updates/` 的日志及备份，修复文件或数据库问题并执行 `php think feifei:schema:upgrade`、`php think feifei:doctor`，确认正常后执行 `php think feifei:update:resume`。
